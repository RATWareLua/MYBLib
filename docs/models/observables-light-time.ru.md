# Наблюдаемые и световое время

[English](observables-light-time.en.md) | **Русский** · [Все паспорта](index.ru.md)

## Что это

Геометрия сигнала между двумя движущимися точками: уравнение светового времени для приёма и
передачи с релятивистской задержкой (Шапиро) от любого числа тел, дальность и скорость
дальности, двусторонние измерения, аберрация преобразованием Лоренца, отклонение света в
PPN-форме, прямое восхождение и склонение. Поверх этого — измерения наземной или космической
станции со световым временем (дальность, скорость дальности, RA/Dec, азимут и высота, одно- и
двухпутные), несущие точные производные по состоянию для [оценивания](estimation.ru.md).
Дисперсионные задержки сред — отдельно: [ионосфера и плазма](ionosphere-plasma.ru.md),
[тропосфера](troposphere.ru.md); смещённое место станции —
[смещения пункта](site-displacement.ru.md).

## Источник

- I. I. Shapiro, *Phys. Rev. Lett.* 13, 789 (1964); T. D. Moyer, *Formulation for Observed and
  Computed Values of Deep Space Network Data Types*, DESCANSO Monograph 2 (2003), ур. 8-38,
  8-55 и §8.3.1 (тело берётся в положении, когда луч проходит мимо него).
- Аберрация — точное преобразование Лоренца; отклонение — PPN-форма `eraLd` из ERFA.
- Написано по формулам; CSPICE и ERFA служат только эталонами.

## Входы и выходы

- Одна инерциальная система (BCRS для Солнечной системы) со своей координатой времени (TDB);
  состояния в м и м/с; c в м/с; PPN γ (1 в ОТО).
- Световое время: c (t − t_e) = |x_o(t) − x_T(t_e)| + c Σ Δt_B, решается неподвижной точкой
  (сжатие |v_T| / c) до разрешения времени.
  Δt_B = (1 + γ) gm_B / c³ ln[(r₁ + r₂ + r₁₂ + (1 + γ) gm_B / c²) /
  (r₁ + r₂ − r₁₂ + (1 + γ) gm_B / c²)] — члены с gm под логарифмом сохраняют значимость у
  края диска. `myb_light_path` даёт момент и состояние цели, световое время, дальность,
  входящую в него задержку, скорость дальности у наблюдателя (ньютоново световое время) и
  число итераций.
- Двустороннее измерение: станция принимает в момент t; `total` = t − t_transmit, с моментом
  отражения.
- Аберрация: p′ = (p / g + (1 + p·b / (1 + 1/g)) b) / |…|, b = v / c, 1/g = √(1 − b²), точно
  по v / c. Отклонение: p + (1 + γ) gm / (c² e_m) / max(q·(q + e), d_lim) (p × (e × q)), без
  нормировки. RA в [0, 2π).
- Измерения со световым временем: то, что станция принимает в модельный момент t, вышло от
  объекта на τ раньше, c τ = |x(t − τ) − s(t)|; в двухпутном станция послала его ещё на τ_up
  раньше, c τ_up = |x(t − τ) − s(t − τ − τ_up)|. Где был объект, находится из его состояния в
  момент t движением вокруг точечной массы gm за τ, до третьего порядка (остаток 10⁻¹⁴ м на
  низкой орбите, 10⁻⁸ м на расстоянии Луны); при gm = 0 — по прямой. Дальность: однопутная
  c τ, двухпутная c (τ + τ_up) / 2 (м); скорость дальности — по времени приёма (м/с); RA/Dec
  и азимут (от севера к востоку) / высота, с `aberration` — как их видит движущаяся станция.
  Производные по состоянию точны, включая производные неявного τ (дуальные числа через
  неподвижную точку).

## Область применимости

- `myb_light_time`: `MYB_E_DOMAIN` (негодная модель, например c ≤ 0), `MYB_E_NOCONV` (не
  сошлось за 32 итерации), статусы провайдеров.
- Измерения со световым временем: `MYB_E_DOMAIN` (неположительное c, отрицательное gm,
  объект в станции или в начале координат, углы на полюсе своих осей), `MYB_E_NOCONV` (нет
  светового времени: конец движется быстрее света), статусы окружения.
- Движение объекта за τ в измерениях — кеплерова дуга вокруг точечной массы: годится для
  орбит вокруг начала окружения, с указанными остатками.

## Ограничения

- Задерживающее тело берётся в момент t − |x_B − x_o| / c — приближение Мойера к его
  положению, когда луч проходит мимо; отклонение — первого порядка по gm, с ограничителем у
  края диска.
- Скорость дальности в `myb_light_path` — по ньютонову световому времени.
- В измерениях со световым временем нет ни релятивистской задержки, ни задержек сред — их
  прибавляют как поправки наблюдённого значения, — ни перевода шкал времени: всё на модельном
  времени окружения.
- Движение объекта за световое время — дуга вокруг точечной массы в начале окружения:
  другие силы за τ не учитываются (остатки выше — для этого движения).
