# Гравитационные поля в сферических гармониках

[English](spherical-harmonics.en.md) | **Русский** · [Все паспорта](index.ru.md)

## Что это

Потенциал, ускорение и градиент ускорения протяжённого тела, разложенные по полностью
нормированным сферическим гармоникам в связанной с телом системе: до степени 2700 для
потенциала и ускорения, до 2698 для градиента, полюсы — обычные точки. Коэффициенты берутся из
файлов ICGEM вместе с переменными во времени членами или из массивов; поправки (приливы,
полюсный прилив) добавляются сверху до следующей смены времени. Готовый член вычисляет поле в
инерциальных осях через ориентацию тела, сам доводит коэффициенты до момента, даёт
аналитический якобиан, а для центрального тела — косвенный член его фигуры.

## Источник

- Вычисление: прямая столбцовая рекурсия S. A. Holmes, W. E. Featherstone, *J. Geodesy* 76,
  279 (2002), с секториальными затравками P̄ₘₘ, масштабированными на 2⁹³⁰, так что степень 2700
  остаётся в диапазоне на любой широте. В производных нет деления на cos φ: столбцы
  P̄ₙₘ / cos φ рекурсируются от своих затравок, а
  dP̄ₙₘ/dφ = eₙₘ P̄ₙ,ₘ₊₁ − m sin φ P̄ₙₘ / cos φ.
- Градиент: вторые производные шаровой функции степени n — шаровые функции степени n + 2
  (Cunningham 1970; Montenbruck & Gill, ур. 3.33); пять независимых компонент — ряды того же
  вида, что суммируются той же столбцовой рекурсией.
- Файлы: форматы ICGEM 1.0 и 2.0 (`gfc`; `gfct`, `trnd`, `acos`, `asin`, эпохи
  `yyyymmdd[.hhmm]`).
- Написано по статьям; стороннего кода нет.

## Входы и выходы

- V(r, φ, λ) = GM/r Σₙ (R/r)ⁿ Σₘ P̄ₙₘ(sin φ) (C̄ₙₘ cos mλ + S̄ₙₘ sin mλ): геоцентрическая
  широта, полностью нормированные присоединённые функции Лежандра в геодезическом соглашении,
  без фазы Кондона–Шортли. Массивы коэффициентов индексируются n (n + 1)/2 + m.
- Положения — в м в связанной системе. Потенциал — в м²/с², **положительный** (GM/r для точечной
  массы); ускорение — в м/с², его градиент; градиент — в с⁻², `gradient[3 i + j]` = ∂aᵢ/∂rⱼ,
  симметричный и вне тела бесследовый.
- Диапазон степеней n_min … n_max (n_max = −1 — все; n_min = 2 исключает центральный член и
  члены степени 1).
- Ключи ICGEM: `earth_gravity_constant` (или `gravity_constant`), `radius`, `max_degree`,
  `norm` (только `fully_normalized`), `tide_system`, `format`; усечение по степени при
  чтении; отсутствующие коэффициенты — нули. Заявленная система приливов (`tide_free`,
  `zero_tide`, `mean_tide` или пусто) сообщается, но не пересчитывается.
- Действующие коэффициенты = статические + переменные во времени члены на момент t (TT, как
  у моделей; тренды — в год, периоды — в годах) + поправки, добавленные после последнего
  `set_time`.
- Член: x — относительно начала окружения в его инерциальных осях; поле поворачивается
  ориентацией тела. Для тела не в начале (когда тело в начале есть) вычитается то же поле в
  начале — косвенная часть. С `update` коэффициенты следуют за временем; с `tides` приливные
  изменения от тел `raisers` применяются раз на момент, в момент на шкале ориентации тела (TT
  для Земли).
- `myb_term_field_indirect`: a = Σⱼ (GMⱼ / GM) g(rⱼ), g — поле без степеней 0 и 1 в точке
  поднимающего тела j, то есть ускорение начала координат фигурой центрального тела. От
  объекта не зависит.

## Область применимости

- Степени 0 … 2700 (`myb_gravity_field_create` отказывает на 2701); градиент — до
  n_max = 2698; рабочая память должна быть создана не меньше чем на n_max.
- Ряды сходятся вне сферы Бриллюэна тела. Внутри неё они могут расходиться: для бруска
  4 × 2,4 × 1,6 точный сферический ряд даёт ошибку от 3,8·10⁻² до 0,26 при степенях от 4 до 16
  (`test_ellipsoidal`) — для таких тел см.
  [тела неправильной формы](irregular-bodies-gravity.ru.md).
- `MYB_E_DOMAIN`: r = 0 или неконечное, степени вне поля или рабочей памяти, gm ≤ 0,
  radius ≤ 0, неконечные коэффициенты или поправки, поправка вне поля; косвенный член тела,
  которое не в начале.
- `MYB_E_FORMAT` (диагностика даёт строку): нет GM, нормировка не `fully_normalized`, нет
  `end_of_head`, короткая строка, m > n, `gfct` без эпохи, периодический член без периода,
  тренд без `gfct`. Также `MYB_E_NOMEM`, `MYB_E_OVERFLOW`.
- `set_time`, поправки и приливы меняют поле: не одновременно с вычислениями. Одно поле
  (`myb_gravity_field_clone`) и одна рабочая память на поток.

## Ограничения

- Только полностью нормированные коэффициенты. Система приливов файла сообщается, но не
  пересчитывается; постоянный прилив zero-tide поля учитывают приливы
  ([приливы IERS 2010](tides-iers.ru.md)).
- Переменные во времени члены — только видов ICGEM 2.0: статическая часть с эпохой, тренд,
  косинусные и синусные члены с периодами.
- Внутри сферы Бриллюэна особой обработки нет: ряд используется как есть.
- Объект поля хранит состояние (время, поправки): один объект на поток.
- У косвенного члена нет якобиана (`myb_term_no_jacobian`): от объекта он не зависит.
