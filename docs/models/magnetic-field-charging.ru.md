# Магнитные поля, плазма и зарядка

[English](magnetic-field-charging.en.md) | **Русский** · [Все паспорта](index.ru.md)

## Что это

Электромагнитная сторона окружения объекта. Магнитные поля тел по коэффициентам Гаусса, в том
числе из таблиц в формате IGRF с вековой вариацией; сила Лоренца; электрическое поле плазмы,
вращающейся вместе с планетой; передача импульса радиальным потоком плазмы (солнечный ветер). И
заряд, который проводящий шар принимает в плазме: токи, ограниченные орбитальным движением
(OML), для дрейфующих сортов частиц, фотоэмиссия, вторичные электроны, два предела слоя,
плавающие потенциалы, уравновешивающие токи, дебаевская длина.

## Источник

- Внутреннее поле: V = a Σₙ (a/r)ⁿ⁺¹ Σₘ (gₙₘ cos mλ + hₙₘ sin mλ) Pₙᵐ(sin φ), полунормировка
  Шмидта (без фазы Кондона–Шортли), B = −∇V; вычисляется кодом сферических гармоник
  [`myb/grav.h`](../../include/myb/grav.h) с Pₙᵐ = P̄ₙₘ / √(2n + 1).
- IGRF-14 (IAGA, отделение V, рабочая группа V-MOD), таблица NOAA NCEI: линейно по времени между
  эпохами, после последней — вековая вариация (предписание IGRF).
- Токи OML: H. M. Mott-Smith, I. Langmuir, *Phys. Rev.* 28, 727 (1926); для дрейфующей плазмы
  E. C. Whipple, *Rep. Prog. Phys.* 44, 1197 (1981) — замкнутые формы через erf и erfc, ряд по M²
  при M < 10⁻³. erf и erfc — из fdlibm (FreeBSD msun `s_erf.c`, лицензия SunPro; см.
  THIRD_PARTY_NOTICES.md).
- Вторичные электроны: E. J. Sternglass (Westinghouse Sci. Pap. 1772, 1954) в форме Whipple
  (1981) и NASCAP, δ(E) = e² δ_max (E/E_max) exp(−2 √(E/E_max)). Тонкий слой: поток Бома
  (D. Bohm, 1949) для притягиваемых ионов.
- ppigrf 2.1.0 (лицензия MIT) — только эталон.
- Написано по статьям; стороннего кода, кроме erf, нет.

## Входы и выходы

- Коэффициенты — в теслах, индекс n (n + 1) / 2 + m (n = 0 не используется); опорный радиус a
  задаёт пользователь (6371,2 км для IGRF); r — в связанной с телом системе (м), φ —
  геоцентрическая широта; B — в теслах в связанной системе.
- Таблица IGRF: столбцы g/h, n, m, затем коэффициенты на эпохи строки заголовка
  «g/h n m 1900.0 … 2025.0 2025-30» в нТл, последний столбец — вековая вариация в нТл/год; поле
  строится на одну десятичную дату.
- Лоренц: a = (q/m) (E + v × B), q/m — Кл/кг, E — В/м, B — Тл, всё в одной инерциальной системе.
  Коротация: E = −(Ω × r) × B.
- Поток плазмы: ρ = ρ₀ (r₀/|r|)², течёт со скоростью `speed` от источника; w = speed r̂ − v;
  a = (c_d/2) (A/m) ρ |w| w (c_d ≈ 2 при полной передаче импульса).
- Сорт частиц: заряд (Кл), масса (кг), плотность (м⁻³), температура как kT (Дж), дрейф
  относительно тела (м/с, ≥ 0). Фотоэмиссия: плотность испускаемого тока с освещённого сечения
  (А/м²), kT фотоэлектронов, e. Потенциал φ (В) — относительно невозмущённой плазмы;
  положительный ток заряжает тело положительно. Заряд плавающего шара Q = 4π ε₀ a φ, его q/m
  идёт в `myb_lorentz_acceleration`.
- Вторичные: δ_max, E_max (Дж), kT вторичных (Дж); положительный потенциал выпускает долю
  (1 + χ_s) e^(−χ_s); для максвелловских электронов энергии удара взвешены по их потоку.
- Слой: `MYB_SHEATH_THICK` (по умолчанию) — шар мал по сравнению с дебаевской длиной, токи OML;
  `MYB_SHEATH_THIN` — a ≫ λ_D: притягиваемый сорт приносит не больше своего тока при нулевом
  потенциале (с дрейфом), притягиваемые ионы — не меньше потока Бома; отталкиваемый сорт
  задерживается множителем e^(−χ).
- `myb_charging_equilibrium`: корень тока, скобка расширяется от 0 шагами наибольшего kT/|q|,
  затем бисекция до разрешения double. `myb_charging_equilibria`: корни в пределах ±200 ×
  наибольшее kT/|q| шагами в его восьмую часть, бисекция до соседних double; устойчивые (ток
  падает с ростом φ) — по возрастанию, каждый — последний double с положительным током, не больше 3.
- Дебаевская длина: √(ε₀ / Σ q² n / kT); 0 без сортов.

## Область применимости

- `myb_magnetic_field_create`: `MYB_E_DOMAIN` (степень < 1, радиус ≤ 0, неконечные
  коэффициенты), `MYB_E_NOMEM`. `myb_magnetic_field_load_table`: `MYB_E_FORMAT` (строка — в
  диагностике), `MYB_E_RANGE` для года раньше первой эпохи, `MYB_E_NOMEM`. Верхней границы нет:
  после последней эпохи вековая вариация продолжается линейно (IGRF-14 задаёт её на 2025–2030).
  `myb_magnetic_field_eval`: `MYB_E_DOMAIN` при r = 0 или неконечном; рабочая память — не меньше
  степени поля.
- Зарядка: `MYB_E_DOMAIN` — неверные сорта или радиус, неизвестный слой, токи одного знака (нет
  равновесия), нет корня в пределах ±200 kT/|q|; `MYB_E_NOCONV`.
- Толстый предел требует a ≪ λ_D, тонкий — a ≫ λ_D; между ними (a ~ λ_D) не верен ни один.

## Стоимость

Не измерялась.

## Ограничения

- Только поле внутренних источников; его зависимость от времени — линейная, по таблице.
- Готового члена модели сил нет: поле, заряд и ускорение Лоренца складывает пользователь.
- Зарядка даёт плавающие потенциалы, а не процесс заряжения; шар — проводник вдали от других
  (Q = 4π ε₀ a φ).
- Вторичная эмиссия: максвелловские электроны, их дрейф не учитывается. Бистабильности для
  максвелловской плазмы не найдено (ни одна из сетки двухтемпературных плазм не дала двух
  равновесий), и она не заявляется.
- Только два предела слоя; поток плазмы радиальный, ρ ∝ r⁻², одна скорость.

## Данные

- `igrf14coeffs.txt` — коэффициенты Гаусса IGRF-14 1900–2025 с вековой вариацией (IAGA,
  NOAA NCEI); загружается `cmake/FetchData.cmake` с проверкой SHA-256, в репозитории не хранится.
  Нужен только для IGRF; любое поле можно задать его коэффициентами.
- `tests/data/magnetic/igrf_reference.txt` — эталонные значения ppigrf для теста.
