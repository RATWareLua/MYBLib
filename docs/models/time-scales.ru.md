# Шкалы времени

[English](time-scales.en.md) | **Русский** · [Все паспорта](index.ru.md)

## Что это

Моменты времени и преобразования между шкалами. Момент — целые секунды (int64) и доля в
[0, 1) от J2000.0 своей шкалы. Шкалы не встроены: система времени — дерево, собранное из
переменных ядра: TAI в корне, TT, TCG, TDB, TCB, GPS, GST, BDT заданы соотношением с родителем
(сдвиг, ход или ряд). UTC — не шкала дерева, а календарные метки TAI, которые читаются через
таблицу секунд координации с датой истечения. TDB − TT по умолчанию берётся из ряда
Ферхеда–Бретаньона; вместо него можно задать функцию (эфемериду времени DE440t) или свести
соотношение в таблицу ради скорости. Окружение модели сил держит свою таблицу для шкал своих
провайдеров.

## Источник

- Определения: резолюция МАС 1991 A4, резолюция МАС 2000 B1.9 (TT, TCG, L_G), резолюция МАС
  2006 B3 (TDB, TCB, L_B, TDB0); IS-GPS-200 для GPS; времена ГНСС — номинальные сдвиги от TAI
  (`data/time/time-scales.tk`).
- TDB − TT: L. Fairhead, P. Bretagnon, *A&A* 229, 240 (1990), полные 787 членов в том виде, в
  каком их распространяет IAU SOFA (`iau_DTDB`), и пять поправок на массы JPL из `eraDtdb`;
  числа перенесены дословно из ERFA `src/dtdb.c` (BSD-3) в `data/time/tdb-tt-fb1990.tk`.
- UTC: до 1972 г. — строки USNO `tai-utc.dat` по таблице ERFA `dat.c` (BSD-3); с 1972 г. —
  `Leap_Second.dat` IERS (бюллетень C 72, июль 2026), каждая строка сверена с ERFA.
- TDB − TT из эфемериды: файл JPL `de440t.bsp`, где TT − TDB в геоцентре лежит первой
  координатой «тела» 1000000001 относительно 1000000000.
- Код библиотеки свой; ERFA компилируется только в тесты как эталон SOFA.

## Входы и выходы

- Момент: `s` целых секунд и `f` ∈ [0, 1) от J2000.0 (JD 2451545,0) своей шкалы; разрешение
  лучше 10⁻¹⁶ с на ±2,9·10¹¹ лет. Разности — в двойной арифметике (`myb_time_diff`,
  относительная ошибка < 2⁻¹⁰³).
- Юлианские даты — из двух частей: на выходе jd1 = 2451545,0 + целые сутки, 0 ≤ jd2 < 1.
- Календарь — пролептический григорианский с астрономическим счётом лет (год 0 = 1 г. до н. э.);
  секунда в [0, 60) на непрерывной шкале, в [0, 60 + скачок) в метке UTC.
- Виды соотношений ядра: OFFSET (X = FROM + OFFSET), RATE и RATE_INVERSE (аффинное соотношение
  с ходом около T0, заданного точной юлианской датой из двух частей), SERIES (X = FROM + S(X),
  решается итерацией).
- `myb_timesys_convert`: сдвиги не добавляют ошибки сверх последнего округления доли, ход
  считается в двойной арифметике, ряды итерируются до ошибки ниже 10⁻¹⁵ с.
- Функция из `myb_timesys_set_difference` возвращает «шкала − родитель» в секундах на момент
  шкалы; `myb_spk_time_difference` — TDB − TT на момент TDB.
- `myb_timesys_tabulate`: узлы через `step` с (0 — час) между t0 и t1 шкалы, кубика по четырём
  узлам вокруг момента; вне таблицы — прежнее соотношение; значения зависят только от узлов.
- Окружение: время модели t — секунды от `epoch` на шкале `scale`; каждый провайдер получает
  тот же момент на шкале, с которой зарегистрирован, из таблицы с шагом `table_step` с
  (0 — 3600), Лагранж по четырём узлам — чистая функция t.

## Область применимости

- Арифметика `myb_time`: конечные аргументы, |секунды| < 2⁶²; календарь: |год| ≤ 10⁹
  (иначе `MYB_E_DOMAIN`, как и для неверной даты или секунды ≥ 60).
- Таблица UTC — от 1960-01-01 до даты истечения 2027-06-28 (не включая):
  `myb_timesys_from_utc` даёт `MYB_E_RANGE` до первой строки и с даты истечения,
  `MYB_E_DOMAIN` для неверной метки (23:59:60 в день без скачка; последняя минута 1961-07-31
  длиной 59,95 с), `MYB_E_NOT_FOUND` без таблицы UTC.
- Ряд верен до нескольких нс на 1950–2050 (примечание ERFA: ±3 нс против эфемерид времени,
  проинтегрированных с DE405); тесты сверяют его с ERFA на 1550–2450.
- DE440t: вне файла `myb_spk_time_difference` даёт `MYB_E_RANGE`, как и преобразование через
  неё.
- `myb_timesys_create`: `MYB_E_NOT_FOUND` (нет переменной), `MYB_E_FORMAT` (цикл, неизвестный
  вид, неупорядоченная таблица UTC), `MYB_E_NOMEM`; diag называет переменную.
- `myb_timesys_set_difference`, `myb_timesys_tabulate`: `MYB_E_DOMAIN` для шкалы, чьё
  соотношение — не ряд, t1 не позже t0, отрицательного или неконечного шага, более 2²⁶ узлов.
- Окружение: не более `MYB_ENV_MAX_SCALES` = 4 шкал кроме шкалы модели; `MYB_E_DOMAIN` для
  шага отрицательного, неконечного или больше 10¹⁵ с; `MYB_E_RANGE` при |t| больше 10¹⁷ с или
  2⁵² шагов таблицы.

## Стоимость

- Преобразование TT → TDB считает ряд из 787 членов дважды (после первого раза ошибка
  < 2·10⁻¹² с, после второго < 2·10⁻²¹ с) — 92 мкс (фаза 20).
- Через часовую таблицу преобразование занимает доли микросекунды (`test_time` печатает оба
  времени); окружение считает ряд раз в час времени модели.

## Ограничения

- Шкалы — значения времени выполнения, а не типы C: смешение двух шкал ловится только явным
  преобразованием через дерево, а не компилятором.
- Ряд — модель релятивистского соотношения TCB − TCG с точностью в несколько нс; дана только
  геоцентрическая часть. Топоцентрические члены относятся к собственному времени наблюдателя —
  см. [релятивистские поправки 1PN](relativity-1pn.ru.md).
- Времена ГНСС номинальные (TAI − 19 с, TAI − 33 с): их реализации отличаются на наносекунды,
  и библиотека этого не моделирует.
- UT1 — не шкала дерева, он берётся из EOP — см. [ориентацию Земли](earth-orientation.ru.md).
- Таблица секунд координации — файл: новый скачок требует новой строки и новой даты
  истечения; до этого преобразования за датой истечения дают отказ, а не догадку.
- У CSPICE TDB − TT из одного члена: эпохи, сверяемые с SPICE, расходятся из-за этого (эпохи
  TLE фазы 15 совпадают с `getelm` в пределах 19 мкс).
- `myb_timesys_set_difference` и `myb_timesys_tabulate` нельзя вызывать, пока другой поток
  преобразует.

## Данные

В репозитории (формат текстовых ядер NAIF):

- `data/time/time-scales.tk` — дерево TAI, TT, TCG, TDB, TCB, GPS, GST, BDT (константы МАС и
  IERS; определения — факты).
- `data/time/tdb-tt-fb1990.tk` — 787 + 5 членов TDB − TT (из ERFA `dtdb.c`, BSD-3).
- `data/time/utc-tai.tk` — TAI − UTC с 1960 г., истечение MJD 61584 = 2027-06-28 (ERFA
  `dat.c`, BSD-3; `Leap_Second.dat` IERS).

По желанию (`-DLARGE=ON`): `de440t.bsp` (JPL, 152 МБ, SHA-256 в `cmake/FetchData.cmake`) —
для TDB − TT из эфемериды.
