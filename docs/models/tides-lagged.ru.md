# Запаздывающие приливы: приливная диссипация

[English](tides-lagged.en.md) | **Русский** · [Все паспорта](index.ru.md)

## Что это

Приливная диссипация как запаздывание приливного горба. Две модели. Постоянное запаздывание
Миньяра: точечная масса поднимает прилив на вращающемся теле, горб стоит там, где
поднимающее тело было время Δt назад, и оно чувствует силу поперёк радиуса, меняющую орбиту, —
с аналитическим якобианом и моментом на тело (что получает орбита, теряет вращение). И в системе
тел — прилив по полосам эфемерид JPL: долгопериодная, суточная и полусуточная полосы, у каждой
своё число Лява, своё орбитальное и своё вращательное запаздывание; прилив действует на третье
тело или на само поднимающее, с реакцией на тело.

## Входы и выходы

- Миньяр: тело (GM, число Лява k₂, радиус R, угловая скорость ω в рад/с в осях r), GM
  поднимающего тела, его r и v относительно тела (м, м/с), запаздывание Δt (с):
  a −= 3 k₂ gm_raiser (1 + gm_raiser/gm_body) R⁵/r⁸ { [r] + Δt [2 (r·v) r/r² + r × ω + v] };
  член [r] — прилив без задержки, который уже дают приливы поля, — только с `with_static`. Для
  круговой экваториальной орбиты da/dt = 6 k₂ Δt (m/M)(R/a)⁵ n a (ω − n). Прилив, поднятый
  телом на поднимающем, — тот же вызов с переставленными ролями.
- `myb_torque_tidal_lag`: момент того же прилива на тело, на единицу его массы (единица
  `myb/attitude.h`), в осях r; записывается, а не прибавляется.
- Член: движение спутника вокруг планеты; вращение тела — из его ориентации, `gm_object` — GM
  объекта, `k2`, `lag` (с), `with_static`.
- Прилив по полосам: тело T в точке r_T создаёт в точке r
  U = G m_T R⁵/(2 |r|⁵) Σⱼ k₂[j] Wⱼ(r, r*ⱼ) / |r*ⱼ|⁵, где
  W₀ = (3z² − |r|²)(3z*² − |r*|²)/2, W₁ = 6 z z* (ρ·ρ*), W₂ = 3 (2 (ρ·ρ*)² − ρ² ρ*²)/2
  (z — вдоль полюса, третьей оси системы тела, ρ — поперёк); при равных полосах это
  k₂ G m_T R⁵ P₂(cos) / (|r|³ |r*|³). Поднимающее тело берётся там, где оно было:
  r*ⱼ = R_pole(rotation_rate · rotation_lag[j]) r_T(t − orbital_lag[j]), прежнее положение —
  из ряда Тейлора до третьего порядка по движению в момент t (рывок — только двух тел; история
  не хранится). Точку ускоряет градиент, тело получает реакцию; поднимающее тело и точка могут
  совпадать.
- `myb_system_tide`: `radius` (м, > 0), `k2[3]`, `orbital_lag[3]` (с, может быть
  отрицательным), `rotation_lag[3]` (с; [0] не используется — долгопериодная полоса не
  поворачивается), `rotation_rate` (рад/с).

## Область применимости

- Миньяр: первый порядок по запаздыванию; `MYB_E_DOMAIN` при r = 0 и неверных входах.
- Прилив по полосам: к моменту запроса ускорений у тела должна быть система, заданная
  ориентацией. `myb_system_set_tide` отказывает (`MYB_E_DOMAIN`) телу с интегрируемым вращением,
  неположительному радиусу и неконечным значениям. До `MYB_SYSTEM_MAX_TIDES` = 64 троек (тело,
  поднимающее, точка).
- Прежнее положение по ряду измерено для запаздывания 900 с на орбите в 27 суток:
  запаздывания должны быть малы по сравнению с периодом орбиты.

## Ограничения

- Миньяр: одно число Лява степени 2, постоянное время запаздывания, первый порядок по нему,
  точечное поднимающее тело.
- Прилив по полосам: только степень 2, три полосы относительно полюса тела, постоянная
  скорость вращения; прежние положения — из ряда в момент t, рывок — только двух тел.
- Член даёт только прилив, который объект сам поднимает на теле (спутник вокруг планеты).
