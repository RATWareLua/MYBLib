# myb — план библиотеки

Библиотека расчёта движения объектов в космосе: N тел, околопланетные орбиты, межпланетные
перелёты, свободное движение. Цель — модели на реальных законах физики, без упрощений там, где
эффект измерим, с воспроизводимым до бита результатом и оценкой погрешности.

## 1. Решения

| Вопрос | Решение |
|---|---|
| Язык | C23 внутри (Clang ≥ 19); публичные заголовки — общее подмножество C17 и C++17 |
| Компилятор | **только Clang, только CMake**; Windows: цель `x86_64-w64-windows-gnu` (sysroot MSYS2 MINGW64, lld), Linux: системный Clang |
| Платформы проверки | Windows 10 (хост), Gentoo (ВМ) |
| Лицензия | BSD-3-Clause; переносится только код с совместимой лицензией (§9) |
| Префикс | `myb_` / `MYB_` |
| N-body | только точное прямое суммирование; приближённые деревья в ядро не входят |
| Точность | ошибка модели ниже шума округления там, где это возможно; где `double` мало — double-double; результат = значение + оценка погрешности |
| Воспроизводимость | побитово одинаковый результат на Windows и Linux, при любом `-O`, числе потоков и SIMD-ядре |

## 2. Принципы

Большие ошибки дают не формулы, а их «бухгалтерия»:

| Ловушка | Цена |
|---|---|
| время одним `double` JD | шаг ≈ 40 мкс → ~0,3 м на НОО, ~1,2 м для Земли |
| TT вместо TDB (±1,66 мс) | ~13 м вдоль НОО, ~50 м в положении Земли |
| UTC вместо UT1 (до 0,9 с) | до ~400 м на поверхности |
| без движения полюса | ~10 м |
| «J2000» вместо ICRF (23 mas) | ~17 км на 1 а.е. |
| `G*M` вместо `GM` (2·10⁻⁵ против 2·10⁻⁹) | порядка км/сут на ГСО |
| `-ffast-math`, FMA-слияние на одной платформе и не на другой | разные результаты; в хаотичной N-body — макроскопически |
| средние элементы TLE в уравнение Кеплера | километры |

Сквозные правила:
1. **GM, а не G и M.** Масса допускается только как пользовательский параметр (тогда GM = G·M с σ от G).
2. **Каждое значение несёт шкалу времени, систему отсчёта и центр.** Шкалы времени — разные типы C; система — тег с проверкой.
3. **Время — две части:** целые секунды `int64` + дробь `double`. UTC — только календарная форма.
4. **СИ** внутри и в API.
5. **ОТО в пост-ньютоновском приближении** там, где эффект измерим; Ньютон — частный случай.
6. **Паспорт модели** (`docs/models/`): формула → источник с номером уравнения → область применимости → неучтённые эффекты и их порядок → эталонный тест с допуском. Номер уравнения — и в комментарии к коду.
7. **Нет глобального изменяемого состояния**; данные только для чтения разделяемы между потоками.

## 3. Ядро не знает ни одного тела

Ядро — законы и модели в общем виде. Солнце — тело со светимостью, Земля — тело с полем, вращением, атмосферой и приливами. Всё конкретное приходит из данных.

| Где | Что |
|---|---|
| `libmyb` | законы, модели в общем виде, форматы файлов, интеграторы |
| `data/` | конвенции IAU/IERS, каталоги тел — текст с источником и σ каждого числа; большие файлы скачиваются |
| `ext/` | эмпирические модели конкретных тел, не сводимые к данным (NRLMSIS 2.1, JB2008, DTM2020, HWM14) — отдельные цели |
| `tests/`, `examples/` | собирают «Солнечную систему» из `data/` |

Модель тела (всё необязательно, `NULL` = эффекта нет, у каждого числа σ и источник): GM; вид движения (динамическое / кинематическое с провайдером); форма (сфера, трёхосный эллипсоид, многогранник); поле (сферические и эллипсоидальные гармоники с изменением во времени, многогранник, масконы); вращение; тензор инерции, ядро/мантия; приливной отклик (числа Лява k_nm(ω), запаздывание/Q); атмосфера; излучение (светимость L(t), альбедо и ИК поверхности); магнитное поле; поверхность аппарата (пластины, оптика, газ–поверхность, тепло).

Общие формы «земных» понятий:
- **Время:** координатное время глобальной системы, координатное время локальной системы любого тела (обобщение TCG), собственное время часов на любой мировой линии. TT, TDB — аффинные конвенции из данных; UTC — таблица скачков; UT1 — таблица поправок.
- **Вращение тел:** постоянное; полиномы + ряды (вид WGCCRE); CIP/CIO — X, Y, s как ряды Пуассона + угол поворота + табличные поправки (так выражаются IAU 2006/2000A + EOP); табличное (Чебышёв из бинарного PCK); динамическое (уравнения Эйлера с моментами).
- **Системы отсчёта:** глобальная, локальная для тела (обобщение GCRS по Soffel et al. 2003), связанная с телом, орбитальные (RTN, VNC, LVLH), пользовательские.
- **Эфемериды:** читатель SPK — провайдер «сегмент: ID A относительно ID B»; смысл ID задаёт пользователь.

## 4. Всё, что влияет на движение

Критерий включения: эффект моделируется, если его вклад за интервал расчёта больше шума округления. **Бюджет эффектов** (`budget`) оценивает вклад каждого члена в конкретном сценарии и предупреждает, если отключённый эффект превышает допуск.

- **Гравитация тел:** точечные массы; сферические гармоники; эллипсоидальные гармоники (ряд сферических расходится внутри сферы Бриллюэна); однородный многогранник; масконы. *Werner & Scheeres 1997; Garmier & Barriot 2001; Holmes & Featherstone 2002.*
- **Переменность поля:** твёрдые приливы (k_nm(ω)), океанские/атмосферные приливы как наборы гармоник, полюсный прилив, вековые и табличные ряды. *IERS TN36 гл. 6; Wahr 1981.*
- **Протяжённые тела:** взаимный потенциал «фигура–фигура», моменты, связь поступательного и вращательного движения, жидкое ядро. *Borderies 1978; Hou, Scheeres, Xin 2017; Williams et al. 2001.*
- **Приливная диссипация.** *Mignard 1979–80; Efroimsky & Lainey 2007; Williams & Boggs 2016.*
- **ОТО 1PN:** EIH с PPN β, γ; Лензе–Тирринг от спина тел; геодезическая прецессия локальных систем; 1PN-мультиполи (теория DSX). *Will 2018; Soffel et al. 2003; Damour, Soffel, Xu 1991–94.*
- **Высшие PN** (2PN, 2,5PN, спиновые) — для компактных объектов, позже. *Blanchet 2014; Poisson & Will 2014.*
- **Излучение источника:** полутень с угловым размером и потемнением к краю, рефракция в атмосфере затеняющего тела, доплер/аберрация (Пойнтинг–Робертсон). *Vokrouhlický, Farinella, Mignard 1993–94; Robertson 2015; Burns, Lamy, Soter 1979.*
- **Поверхность объекта:** пластины (зеркальное/диффузное/поглощение), самозатенение. *Milani, Nobili, Farinella 1987; Ziebart 2004; Montenbruck et al. 2015.*
- **Излучение тел:** альбедо и ИК. *Knocke et al. 1988; Rodriguez-Solano et al. 2012.*
- **Собственное тепло:** тепловая отдача аппарата, РИТЭГ; Ярковский и YORP; отдача антенны (P/c). *Turyshev et al. 2012; Vokrouhlický 1998–99; Bottke et al. 2006; Farnocchia et al. 2013.*
- **Плазма и поля:** давление солнечного ветра; сила Лоренца. *Horányi 1996.*
- **Атмосфера:** сопротивление и подъёмная сила, вращение атмосферы, ветры; взаимодействие газ–поверхность; свободномолекулярный и переходный режимы. *Sentman 1961; Moe & Moe 2005; Doornbos 2012.*
- **Собственные силы:** тяга, переменная масса, смещение центра масс; газовыделение; кометы (A1, A2, A3, g(r)). *Marsden, Sekanina, Yeomans 1973.*
- **Неинерциальность:** косвенные члены, силы инерции вращающихся систем.
- **События:** столкновение с формой тела, слияние с сохранением импульса и массы.

Вне первой версии: контакт и посадка, сплошная гиперзвуковая аэродинамика (только таблицы пользователя), абляция, стохастические удары микрометеоритов. Позже: наблюдаемые (время света, задержка Шапиро, аберрация, отклонение света).

**Погрешность результата** (`uncert`): вариационные уравнения по состоянию и параметрам, перенос ковариации через STM, Монте-Карло с детерминированным ГСЧ.

## 5. N тел

- Только точное прямое суммирование: O(N²) по массивным телам + O(N·M) для пробных частиц; ориентир — до ~10⁴ массивных тел.
- Граф взаимодействий: уровень задаётся для каждой пары (точка, гармоники, фигура–фигура, 1PN, приливы); по умолчанию точка + 1PN.
- Потоки — через платформенный слой, разбиение по i, сумма по j в фиксированном порядке: результат не зависит от числа потоков и совпадает с однопоточной симметричной версией.
- SIMD — векторизация по i, не по j; без FMA в ядрах; бит в бит со скаляром.
- Барнс–Хат даёт ошибку силы ~10⁻³–10⁻⁴ — не входит. FMM — возможный отдельный модуль, явно помеченный как приближённый.

## 6. Архитектура

```
L0  core, platform (файлы, потоки, CPUID)
L1  num, cmath (свои функции), io (DAF/SPK/PCK, .gfc, ряды IERS, CCSDS, CSV)
L2  time (общая), body (модель тела, параметры ± σ)
L3  frames, kin (провайдеры кинематики), kepler, integ
L4  grav (поля), rel (1PN, локальные системы, собственное время), force (негравитационные)
L5  dyn (тела, пробные частицы, вращение, граф взаимодействий), uncert, budget
L6  orbit, transfer, cr3bp
ext/   эмпирические модели конкретных тел
data/  конвенции и каталоги — только данные
```
Модуль использует только слои ниже; `integ` ничего не знает о физике.

Ключевые методы по модулям (источники — §8):
- **num:** double-double [Dekker 1971; Joldes, Muller, Popescu 2017; Muller & Rideau 2022], Sum2/Dot2 [Ogita, Rump, Oishi 2005], Кленшоу, корни с бюджетом, Лежандр, Штумпф, малая линейная алгебра.
- **time:** резолюции МАС 2000 B1.9, 2006 B3; TDB−TT по ряду Fairhead & Bretagnon 1990 или из эфемериды; таблица секунд координации с датой истечения (`MYB_E_RANGE` за её пределами).
- **frames:** CIO-схема IAU 2006/2000A [Capitaine et al. 2003; IERS TN36 гл. 5], EOP с интерполяцией, WGCCRE [Archinal et al. 2018], Луна — бинарный PCK (система PA), геодезические координаты [Vermeille 2011], матрица и её производная по времени; нутация — сетка + интерполяция с доказанной ошибкой.
- **kin/ephem:** свой читатель NAIF DAF/SPK (типы 2, 3, 13, 21) и бинарного PCK; DE440/DE441 [Park et al. 2021]; сверка по `testpo`.
- **kepler:** элементы (классические, равноденственные, модифицированные равноденственные), уравнение Кеплера [Markley 1995; Raposo-Pulido & Peláez 2017; Conway 1986], универсальные переменные и STM [Shepperd 1985]; SGP4 — только ради TLE [Hoots & Roehrich 1980; Vallado et al. 2006].
- **integ:** IAS15 [Rein & Spiegel 2015], RKN12(10) [Dormand, El-Mikkawy, Prince 1987], DOP853 [Hairer et al.], Гаусс–Джексон [Berry & Healy 2004], WH/WHFast [Wisdom & Holman 1991; Rein & Tamayo 2015], Йошида, SABA/SBAB; плотный вывод, события, компенсированное обновление, закон Брауэра.
- **transfer:** Ламберт [Izzo 2015; Gooding 1990], патч-коники, B-плоскость [Sergeyevsky et al. 1983], коррекция на STM.
- **cr3bp:** точки Лагранжа, Якоби, гало [Richardson 1980; Howell 1984], многообразия [Koon, Lo, Marsden, Ross 2011].

## 7. Плавающая точка и воспроизводимость

Контракт (проверяется сборкой и тестами):
- binary64, `FLT_EVAL_METHOD == 0`, `-ffp-contract=off`, без fast-math, `-fno-math-errno`, базовый уровень x86-64-v2 (v3 допустим); флаги добавляются последними и не перебиваются пользовательскими CFLAGS; `-ffast-math` → ошибка компиляции.
- Никаких функций libm с неточным округлением: `sin`, `cos` и т.д. — корректно округлённые (CORE-MATH), `fma` — своя целочисленная (у mingw-w64 `fma()` ошибается примерно на 1 входе из 6). Тест `test_no_libm_imports` проверяет таблицу символов библиотеки.
- `long double` и `float` в расчётах запрещены.
- Числа из файлов — свой корректно округляющий парсер, не зависящий от локали (Eisel–Lemire; Lemire 2021).
- Хеш результатов (`test_repro`) одинаков на всех сборках; отличие = изменился хотя бы один бит.

## 11. Правила разработки

- Ожидаемые ошибки — `myb_status`; нарушение контракта — `MYB_CHECK` (одна строка в stderr и немедленное завершение).
- Рекурсия запрещена (явный стек); у каждого цикла видимая граница, итерационные алгоритмы — с бюджетом и `MYB_E_NOCONV`.
- Системные вызовы — только `src/platform/`; без выделения памяти в шаге интегратора.
- Код и тесты — вместе; новый код без предупреждений с `-Werror`.

| Фаза | Содержание | Критерий готовности | Статус |
|---|---|---|---|
| 0 | каркас CMake (только Clang), `core`, `num`, `cmath` (fma, sin, cos), тесты воспроизводимости | всё ниже зелёное на Windows и Gentoo | Windows: готово; Gentoo: в конце |

### Решения фазы 2

- **19 корректно округлённых функций CORE-MATH** (tan, atan, atan2, asin, acos, exp, expm1,
  log, log1p, sinh, cosh, tanh, asinh, acosh, atanh, cbrt, hypot + sin, cos) переносятся
  скриптом `third_party/core-math/import.cmake` с тремя механическими правками; путь
  «невозможного трудного случая» в atan2 (upstream: printf + exit) стал fail-fast проверкой.
  `pow` отложен (нужны дополнительные заголовки, в фазе 2 не требуется).
- **Уравнение Кеплера без сокращения**: невязка `(1−e)E + e·(E − sin E) − M` с рядом Штумпфа;
  корни в пределах 2 ulp от точного (MPFR) для e до 1 − 2⁻⁵². Параболическое — замкнутая
  форма + одна поправка Ньютона (≤ 1,2 ulp).
- **Один гарантированный решатель** (`num/root.c`): Ньютон в вилке с правилом rtsafe. Первая
  версия возвращала середину вилки, когда шаг Ньютона был меньше ulp (`next == lo`); найдено
  сверкой с путём через элементы, исправлено, покрыто тестами.
- **Пропагатор**: универсальные переменные; эллипсы — снятие целых периодов в double-double;
  гиперболы далеко от перицентра (|H₀| > 1) — пересчёт от перицентра (иначе члены уравнения
  ~10⁴ раз больше результата). Почти параболические — прямой путь (там α плохо обусловлена,
  а прямому пути она почти не нужна). Сверка с MPFR 400 бит: ≤ 2·10⁻¹⁴.
- **Ламберт** (Izzo 2015) с гарантированным решателем вместо Хаусхолдера; вторым методом
  (Gooding) служит независимая проверка: каждое решение прогоняется пропагатором до r₂.
- **Не сделано в фазе 2**: аналитическая матрица перехода состояния двух тел (Shepperd 1985) —
  перенесена в фазу 3 вместе с вариационными уравнениями интеграторов.
- **Обусловленность элементов**: классические и равноденственные элементы почти параболических
  орбит вдали от перицентра плохо обусловлены (сдвиг ν на ulp меняет r в (1 − e)⁻¹ раз);
  это свойство параметризации, в тестах эта область исключена и описана.

### Решения фазы 1

- **Формат данных — текстовые ядра NAIF.** Документированный формат, в котором JPL уже
  распространяет свои ядра; один загрузчик для наших конвенций и для `gm_de440.tpc` и т.п.
- **Шкалы времени — значения во время выполнения, а не типы C.** План предполагал отдельный тип
  на шкалу, но шкалы задаются данными (ядро не знает слова «TT»), поэтому мгновение — это
  `myb_time`, а шкала — дескриптор `myb_scale` системы `myb_timesys`; смешение шкал ловится
  явным преобразованием по дереву, а не компилятором.
- **UTC — только календарные метки.** UTC не непрерывная шкала; в дереве её нет, а
  преобразования идут через таблицу с датой истечения (после неё — `MYB_E_RANGE`).
- **TDB−TT — ряд Fairhead & Bretagnon** (несколько нс); точное соотношение TCB−TCG по
  эфемериде появится с модулем `rel` (фаза 6). Топоцентрические члены относятся к собственному
  времени наблюдателя и в конвенцию шкалы не входят.
- **Свой разбор чисел**: быстрый путь Клингера + проверка большими целыми относительно середин;
  `strtod` не используется (зависит от локали и CRT).
- **Вывод чисел (Ryu)** отложен до фазы, где появится запись результатов (CCSDS OEM).
