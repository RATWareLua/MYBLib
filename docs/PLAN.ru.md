# myb — план библиотеки

[English](PLAN.en.md) | **Русский**

Библиотека расчёта движения объектов в космосе: N тел, околопланетные орбиты, межпланетные
перелёты, свободное движение. Цель — модели на реальных законах физики, без упрощений там, где
эффект измерим, с воспроизводимым до бита результатом и оценкой погрешности.

## 1. Решения

| Вопрос | Решение |
|---|---|
| Язык | C23 внутри (Clang ≥ 19); публичные заголовки — общее подмножество C17 и C++17 |
| Компилятор | **только Clang, только CMake**; Windows: цель `x86_64-w64-windows-gnu` (sysroot MSYS2 MINGW64, lld), Linux: системный Clang |
| Платформы проверки | Windows 10 (хост), Gentoo (ВМ) |
| Лицензия | BSD-3-Clause; переносится только код с совместимой лицензией (§9) |
| Префикс | `myb_` / `MYB_` |
| N-body | только точное прямое суммирование; приближённые деревья в ядро не входят |
| Точность | ошибка модели ниже шума округления там, где это возможно; где `double` мало — double-double; результат = значение + оценка погрешности |
| Воспроизводимость | побитово одинаковый результат на Windows и Linux, при любом `-O`, числе потоков и SIMD-ядре |

## 2. Принципы

Большие ошибки дают не формулы, а их «бухгалтерия»:

| Ловушка | Цена |
|---|---|
| время одним `double` JD | шаг ≈ 40 мкс → ~0,3 м на НОО, ~1,2 м для Земли |
| TT вместо TDB (±1,66 мс) | ~13 м вдоль НОО, ~50 м в положении Земли |
| UTC вместо UT1 (до 0,9 с) | до ~400 м на поверхности |
| без движения полюса | ~10 м |
| «J2000» вместо ICRF (23 mas) | ~17 км на 1 а.е. |
| `G*M` вместо `GM` (2·10⁻⁵ против 2·10⁻⁹) | порядка км/сут на ГСО |
| `-ffast-math`, FMA-слияние на одной платформе и не на другой | разные результаты; в хаотичной N-body — макроскопически |
| средние элементы TLE в уравнение Кеплера | километры |

Сквозные правила:
1. **GM, а не G и M.** Масса допускается только как пользовательский параметр (тогда GM = G·M с σ от G).
2. **Каждое значение несёт шкалу времени, систему отсчёта и центр.** Шкалы времени — разные типы C; система — тег с проверкой.
3. **Время — две части:** целые секунды `int64` + дробь `double`. UTC — только календарная форма.
4. **СИ** внутри и в API.
5. **ОТО в пост-ньютоновском приближении** там, где эффект измерим; Ньютон — частный случай.
6. **Паспорт модели** (`docs/models/`): формула → источник с номером уравнения → область применимости → неучтённые эффекты и их порядок → эталонный тест с допуском. Номер уравнения — и в комментарии к коду.
7. **Нет глобального изменяемого состояния**; данные только для чтения разделяемы между потоками.

## 3. Ядро не знает ни одного тела

Ядро — законы и модели в общем виде. Солнце — тело со светимостью, Земля — тело с полем, вращением, атмосферой и приливами. Всё конкретное приходит из данных.

| Где | Что |
|---|---|
| `libmyb` | законы, модели в общем виде, форматы файлов, интеграторы |
| `data/` | конвенции IAU/IERS, каталоги тел — текст с источником и σ каждого числа; большие файлы скачиваются |
| `ext/` | эмпирические модели конкретных тел, не сводимые к данным (NRLMSIS 2.1, JB2008, DTM2020, HWM14) — отдельные цели |
| `tests/`, `examples/` | собирают «Солнечную систему» из `data/` |

Модель тела (всё необязательно, `NULL` = эффекта нет, у каждого числа σ и источник): GM; вид движения (динамическое / кинематическое с провайдером); форма (сфера, трёхосный эллипсоид, многогранник); поле (сферические и эллипсоидальные гармоники с изменением во времени, многогранник, масконы); вращение; тензор инерции, ядро/мантия; приливной отклик (числа Лява k_nm(ω), запаздывание/Q); атмосфера; излучение (светимость L(t), альбедо и ИК поверхности); магнитное поле; поверхность аппарата (пластины, оптика, газ–поверхность, тепло).

Общие формы «земных» понятий:
- **Время:** координатное время глобальной системы, координатное время локальной системы любого тела (обобщение TCG), собственное время часов на любой мировой линии. TT, TDB — аффинные конвенции из данных; UTC — таблица скачков; UT1 — таблица поправок.
- **Вращение тел:** постоянное; полиномы + ряды (вид WGCCRE); CIP/CIO — X, Y, s как ряды Пуассона + угол поворота + табличные поправки (так выражаются IAU 2006/2000A + EOP); табличное (Чебышёв из бинарного PCK); динамическое (уравнения Эйлера с моментами).
- **Системы отсчёта:** глобальная, локальная для тела (обобщение GCRS по Soffel et al. 2003), связанная с телом, орбитальные (RTN, VNC, LVLH), пользовательские.
- **Эфемериды:** читатель SPK — провайдер «сегмент: ID A относительно ID B»; смысл ID задаёт пользователь.

## 4. Всё, что влияет на движение

Критерий включения: эффект моделируется, если его вклад за интервал расчёта больше шума округления. **Бюджет эффектов** (`budget`) оценивает вклад каждого члена в конкретном сценарии и предупреждает, если отключённый эффект превышает допуск.

- **Гравитация тел:** точечные массы; сферические гармоники; эллипсоидальные гармоники (ряд сферических расходится внутри сферы Бриллюэна); однородный многогранник; масконы. *Werner & Scheeres 1997; Garmier & Barriot 2001; Holmes & Featherstone 2002.*
- **Переменность поля:** твёрдые приливы (k_nm(ω)), океанские/атмосферные приливы как наборы гармоник, полюсный прилив, вековые и табличные ряды. *IERS TN36 гл. 6; Wahr 1981.*
- **Протяжённые тела:** взаимный потенциал «фигура–фигура», моменты, связь поступательного и вращательного движения, жидкое ядро. *Borderies 1978; Hou, Scheeres, Xin 2017; Williams et al. 2001.*
- **Приливная диссипация.** *Mignard 1979–80; Efroimsky & Lainey 2007; Williams & Boggs 2016.*
- **ОТО 1PN:** EIH с PPN β, γ; Лензе–Тирринг от спина тел; геодезическая прецессия локальных систем; 1PN-мультиполи (теория DSX). *Will 2018; Soffel et al. 2003; Damour, Soffel, Xu 1991–94.*
- **Высшие PN** (2PN, 2,5PN, спиновые) — для компактных объектов, позже. *Blanchet 2014; Poisson & Will 2014.*
- **Излучение источника:** полутень с угловым размером и потемнением к краю, рефракция в атмосфере затеняющего тела, доплер/аберрация (Пойнтинг–Робертсон). *Vokrouhlický, Farinella, Mignard 1993–94; Robertson 2015; Burns, Lamy, Soter 1979.*
- **Поверхность объекта:** пластины (зеркальное/диффузное/поглощение), самозатенение. *Milani, Nobili, Farinella 1987; Ziebart 2004; Montenbruck et al. 2015.*
- **Излучение тел:** альбедо и ИК. *Knocke et al. 1988; Rodriguez-Solano et al. 2012.*
- **Собственное тепло:** тепловая отдача аппарата, РИТЭГ; Ярковский и YORP; отдача антенны (P/c). *Turyshev et al. 2012; Vokrouhlický 1998–99; Bottke et al. 2006; Farnocchia et al. 2013.*
- **Плазма и поля:** давление солнечного ветра; сила Лоренца. *Horányi 1996.*
- **Атмосфера:** сопротивление и подъёмная сила, вращение атмосферы, ветры; взаимодействие газ–поверхность; свободномолекулярный и переходный режимы. *Sentman 1961; Moe & Moe 2005; Doornbos 2012.*
- **Собственные силы:** тяга, переменная масса, смещение центра масс; газовыделение; кометы (A1, A2, A3, g(r)). *Marsden, Sekanina, Yeomans 1973.*
- **Неинерциальность:** косвенные члены, силы инерции вращающихся систем.
- **События:** столкновение с формой тела, слияние с сохранением импульса и массы.

Вне первой версии (теперь — фаза 22, решение пользователя 2026-11-11): контакт и посадка, сплошная гиперзвуковая аэродинамика (только таблицы пользователя), абляция, стохастические удары микрометеоритов. Позже: наблюдаемые (время света, задержка Шапиро, аберрация, отклонение света).

**Погрешность результата** (`uncert`): вариационные уравнения по состоянию и параметрам, перенос ковариации через STM, Монте-Карло с детерминированным ГСЧ.

## 5. N тел

- Только точное прямое суммирование: O(N²) по массивным телам + O(N·M) для пробных частиц; ориентир — до ~10⁴ массивных тел.
- Граф взаимодействий: уровень задаётся для каждой пары (точка, гармоники, фигура–фигура, 1PN, приливы); по умолчанию точка + 1PN.
- Потоки — через платформенный слой, разбиение по i, сумма по j в фиксированном порядке: результат не зависит от числа потоков и совпадает с однопоточной симметричной версией.
- SIMD — векторизация по i, не по j; без FMA в ядрах; бит в бит со скаляром.
- Барнс–Хат даёт ошибку силы ~10⁻³–10⁻⁴ — не входит. FMM — отдельный модуль, явно помеченный как приближённый (фаза 22).

## 6. Архитектура

```
L0  core, platform (файлы, потоки, CPUID)
L1  num, cmath (свои функции), io (DAF/SPK/PCK, .gfc, ряды IERS, CCSDS, CSV)
L2  time (общая), body (модель тела, параметры ± σ)
L3  frames, kin (провайдеры кинематики), kepler, integ
L4  grav (поля), rel (1PN, локальные системы, собственное время), force (негравитационные)
L5  dyn (тела, пробные частицы, вращение, граф взаимодействий), env (окружение и готовые члены модели сил), uncert, budget
L6  orbit, transfer, cr3bp
ext/   эмпирические модели конкретных тел
data/  конвенции и каталоги — только данные
```
Модуль использует только слои ниже; `integ` ничего не знает о физике.

Ключевые методы по модулям (источники — §8):
- **num:** double-double [Dekker 1971; Joldes, Muller, Popescu 2017; Muller & Rideau 2022], Sum2/Dot2 [Ogita, Rump, Oishi 2005], Кленшоу, корни с бюджетом, Лежандр, Штумпф, малая линейная алгебра.
- **time:** резолюции МАС 2000 B1.9, 2006 B3; TDB−TT по ряду Fairhead & Bretagnon 1990 или из эфемериды; таблица секунд координации с датой истечения (`MYB_E_RANGE` за её пределами).
- **frames:** CIO-схема IAU 2006/2000A [Capitaine et al. 2003; IERS TN36 гл. 5], EOP с интерполяцией, WGCCRE [Archinal et al. 2018], Луна — бинарный PCK (система PA), геодезические координаты [Vermeille 2011], матрица и её производная по времени; нутация — сетка + интерполяция с доказанной ошибкой.
- **kin/ephem:** свой читатель NAIF DAF/SPK (типы 2, 3, 13, 21) и бинарного PCK; DE440/DE441 [Park et al. 2021]; сверка по `testpo`.
- **kepler:** элементы (классические, равноденственные, модифицированные равноденственные), уравнение Кеплера [Markley 1995; Raposo-Pulido & Peláez 2017; Conway 1986], универсальные переменные и STM [Shepperd 1985]; SGP4 — только ради TLE [Hoots & Roehrich 1980; Vallado et al. 2006].
- **integ:** IAS15 [Rein & Spiegel 2015], RKN12(10) [Dormand, El-Mikkawy, Prince 1987], DOP853 [Hairer et al.], Гаусс–Джексон [Berry & Healy 2004], WH/WHFast [Wisdom & Holman 1991; Rein & Tamayo 2015], Йошида, SABA/SBAB; плотный вывод, события, компенсированное обновление, закон Брауэра.
- **transfer:** Ламберт [Izzo 2015; Gooding 1990], патч-коники, B-плоскость [Sergeyevsky et al. 1983], коррекция на STM.
- **cr3bp:** точки Лагранжа, Якоби, гало [Richardson 1980; Howell 1984], многообразия [Koon, Lo, Marsden, Ross 2011].
- **env, orbit:** тела сценария с провайдерами состояния и ориентации, значения на момент — один раз; шкалы провайдеров по таблице разностей; готовые члены модели сил; распространение IAS15 со своими шагами и плотным выводом — состояние на момент не зависит от того, что ещё запрошено.

## 7. Плавающая точка и воспроизводимость

Контракт (проверяется сборкой и тестами):
- binary64, `FLT_EVAL_METHOD == 0`, `-ffp-contract=off`, без fast-math, `-fno-math-errno`, базовый уровень x86-64-v2 (v3 допустим); флаги добавляются последними и не перебиваются пользовательскими CFLAGS; `-ffast-math` → ошибка компиляции.
- Никаких функций libm с неточным округлением: `sin`, `cos` и т.д. — корректно округлённые (CORE-MATH), `fma` — своя целочисленная (у mingw-w64 `fma()` ошибается примерно на 1 входе из 6). Тест `test_no_libm_imports` проверяет таблицу символов библиотеки.
- `long double` и `float` в расчётах запрещены.
- Числа из файлов — свой корректно округляющий парсер, не зависящий от локали (Eisel–Lemire; Lemire 2021).
- Хеш результатов (`test_repro`) одинаков на всех сборках; отличие = изменился хотя бы один бит.

## 11. Правила разработки

- Ожидаемые ошибки — `myb_status`; нарушение контракта — `MYB_CHECK` (одна строка в stderr и немедленное завершение).
- `goto` — только переход к метке очистки/ошибки в конце функции (`fail:`, `out:`): в Си нет RAII, и одна метка освобождает все ресурсы на любом пути ошибки. Иное использование `goto` запрещено.
- Рекурсия запрещена (явный стек); у каждого цикла видимая граница, итерационные алгоритмы — с бюджетом и `MYB_E_NOCONV`.
- Системные вызовы — только `src/platform/`; без выделения памяти в шаге интегратора.
- Код и тесты — вместе; новый код без предупреждений с `-Werror`.

### Доведение после 1.1 (фазы 12–22)

Разбор 2026-11-10 показал: физика ядра покрыта, не хватает слоя над ней. Порядок фаз 12–21 —
от того, без чего остальное не построить (готовые члены и распространение, упаковка), к
оцениванию, выводу, событиям, недостающим силам §4, полной задаче N тел, прикладным задачам,
файлам и инженерной части. Привязки к C++, Python и Rust — после фазы 13 (им нужны установка и
разделяемая библиотека) и опираются на фазу 12: модель сил собирается данными, а не
функциями обратного вызова.

То, что фазы 12–17 оставили под заголовком «Не сделано», закрыто отдельным проходом до фазы 18
(раздел «Долги фаз 12–17» ниже); что перенесено в будущие фазы — названо там же с причиной.

Правило для остатков любой фазы (2026-11-11): что закрывается без лишних трудностей —
закрывается сразу; что сейчас сложнее — получает фазу, где оно обойдётся дешевле всего или
принесёт больше всего (либо финальную фазу 22); отказ от пункта — только решением
пользователя. По этому правилу разобраны и остатки фаз 3–11, которые не входили ни в одну
фазу: раздел «Старые долги (фазы 3–11) и привязки» ниже.

### Решения фазы 20

Фаза закрыта: сделано и проверено на Windows и Gentoo. Windows — 106/106 (-O2), затронутые
тесты при -O0 (с бюджетом стека и запретом libm) и под UBSan; Gentoo — linux-release 106/106
с тем же эталоном воспроизводимости, linux-asan на 20 затронутых тестах (с LAGEOS и DE440 с
малыми телами). Что не вошло и куда отнесено — в конце раздела.

- **SPK тип 15** (коника с прецессией узла и перицентра от J₂): правило типа — двухтельное
  движение от перицентра, затем повороты на углы, пропорциональные пройденной истинной
  аномалии (как в SPICE; значения флага 1, 2, 3 сверены). Против CSPICE (`spkw15_c`,
  `spkgeo_c`, 440 состояний: окружность, эллипсы, парабола, гипербола) — 10⁻¹³…1,6·10⁻¹¹:
  это погрешность самого CSPICE, его двухтельное распространение набирает ошибку с числом
  витков. Против того же правила в 60 знаках (mpmath) библиотека — **9·10⁻¹⁶** (положение),
  1,5·10⁻¹⁵ (скорость); на дугах в 3400 витков и у перицентра орбиты e = 0,85 — 1,3·10⁻¹⁴
  (CSPICE там 1,6·10⁻¹¹). Для этого средняя аномалия на эллипсе считается и приводится к
  одному обороту в двойной арифметике: иначе после тысяч витков положение ограничено
  последним битом среднего движения.
- **Граф систем отсчёта** (`myb_frame_graph_*` в `myb/frames.h`): система задаётся в другой —
  своей базе — провайдером ориентации или постоянным поворотом; поворот между любыми двумя
  составляется через первого общего предка, с производными. Шкалы времени — как в окружении:
  граф создаётся на одной шкале, провайдер, зарегистрированный с другой, получает тот же
  момент на своей (TT для вращения Земли среди провайдеров на TDB). Фиксированные системы —
  из ядер (`myb_frame_graph_add_tkframe`). **SPK через разные системы**
  (`myb_spk_state_in`, поле `graph` у `myb_spk_body`): состояние каждого сегмента переводится
  в нужную систему — с поворотом скоростей — до суммирования. Против CSPICE (`spkgeo_c`,
  `sxform_c`; сегменты в ECLIPJ2000, B1950, GALACTIC, FK4, J2000 и во вращающейся системе
  двоичного PCK): 336 состояний — **1,3·10⁻¹⁵** (скорости 3·10⁻¹⁴ — эрмитовы сегменты,
  разница за CSPICE), 126 поворотов между семью системами — 2·10⁻¹⁶, производная — 4·10⁻¹⁶.
- **Часы аппарата и CK** (новый `myb/ck.h`). SCLK типа 1: поля с модулями и смещениями,
  разделы, таблица (отсчёты, время, ход); отсчёты ↔ время на шкале часов (TDB или TT), строки
  ↔ отсчёты. Против CSPICE (`sct2e_c`, `sce2c_c`, `scdecd_c`, `scencd_c`; двое часов, 519
  преобразований): время — 6·10⁻⁸ с (разрешение double секунд от J2000), строки и отсчёты —
  точно. Читатель CK типов 1, 2, 3 с правилом `ckgpav_c`: внутри интервала — на момент
  запроса, вне — ближайший момент в пределах допуска. Против CSPICE на 1302 запросах: какие
  найдены и какие отвергнуты — совпало во всех, матрица — **7·10⁻¹⁶**, угловая скорость —
  9·10⁻¹⁹ рад/с. Найдено по ходу: при равном расстоянии до двух соседних записей CSPICE
  берёт более позднюю (во всех трёх типах) — так и сделано. Система прибора входит в граф
  (`myb_orientation_ck`): против `sxform_c` — 1,3·10⁻¹⁵. **Запись CK** типов 1, 2, 3

- **Начальное определение орбиты** (`myb/iod.h`). Гиббс — три положения, точно для любой
  коники: скорость до 1,4·10⁻¹⁵ при e от 0 до 1,4; пример Валладо 7-3 — (0; 5,531148;
  −5,191806) км/с. Херрик–Гиббс — близкие положения, ошибка падает как четвёртая степень
  шага (отношения 16,0 и 16,0); пример 7-4 — шесть цифр. **Гаусс** — три направления из трёх
  мест: корни многочлена восьмой степени дают кандидатов, каждый уточняется методом Ньютона
  по шести условиям (объект лежит на каждом луче) с матрицей перехода задачи двух тел.
  Низкая орбита за 4 и 12 минут, эксцентрическая за полчаса, навигационная за 2 часа,
  геостационарная высота за 5 часов: орбита возвращается до **5·10⁻¹⁵…3·10⁻¹⁶** за 4–5 шагов
  (один ряд Гаусса даёт 3·10⁻⁵…5·10⁻³). Уточнение простой итерацией по схеме Кёртиса в этих
  геометриях расходится (множитель около −3) — поэтому Ньютон.
- **Относительное движение** (`myb/relative.h`): состояние ведомого в системе R, T, N
  ведущего, точно, туда и обратно; линейная карта относительного состояния для **любой
  коники** — из матрицы перехода задачи двух тел, переведённой во вращающуюся систему на
  обоих концах (то же, что даёт Яманака–Анкерсен на эллипсе и Клохесси–Уилтшир на
  окружности, без формулы на каждый вид орбиты). Ошибка карты — второго порядка по
  разделению: при 10 м, 100 м и 1 км отношения ровно 100 на окружности, эллипсе e = 0,7 и
  гиперболе; на окружности совпадает с замкнутой формой Клохесси–Уилтшира до 3·10⁻¹⁴.
  Двухимпульсная встреча (`myb_relative_rendezvous`): с 5 км за 40 минут, пролетев точно,
  промахивается на 11,6 м — столько и даёт линеаризация. Относительные элементы Д'Амико
  (`myb_roe_from_states`, `myb_roe_to_position`): постоянны до 2·10⁻¹⁰ за виток, кроме
  дрейфа второго.
- **Сближения и вероятность столкновения** (`myb/conjunction.h`). Ближайшие сближения двух
  объектов — минимумы расстояния: для провайдеров (`myb_approach_find`, до разрешения
  времени) и для двух распространяемых орбит (`myb_approach_orbits`, кубика по концам шага;
  против провайдеров — 2·10⁻¹¹ с и 10⁻⁸ м при шаге 10 с). Две окружности, пересекающиеся в
  узле, и компланарные окружности — замкнутые формы. Вероятность короткого сближения
  (`myb_encounter_plane`, `myb_collision_probability`): интеграл гауссианы по диску сведён к
  одному интегралу разности функций ошибок (в хвостах — через erfc, без вычитания близких
  чисел), панели Гаусса–Лежандра удваиваются до 10⁻¹³. Центрированная круглая гауссиана
  против 1 − exp(−R²/2σ²) — 2·10⁻¹⁶; смещённая (до 30σ, вероятности до 8·10⁻¹⁹⁰) против ряда
  Райса — 4·10⁻¹⁴; неравные σ против суммы по сетке 4000 × 4000 — 2·10⁻⁶. Ряд Чана
  (`myb_collision_probability_chan`) суммируется с положительными членами (в исходной
  записи он теряет все цифры при больших промахах); наибольшая вероятность по масштабу
  ковариации (`myb_collision_probability_max`) против R²/(e d²) — 10⁻⁶.
- **Средние элементы и подгонка TLE**. Численное осреднение (`myb_mean_elements_average`,
  `myb/kepler.h`): под J₂ оскулирующая полуось качается на 11,5 км, средняя держится до
  0,75 м, e — до 4·10⁻⁷; дрейф узла совпадает с теорией первого порядка до 7·10⁻⁴, скорость
  средней долготы — до 4·10⁻⁷. Подгонка набора элементов SGP4 к положениям (`myb_tle_fit`,
  `myb_tle_from_state` в `ext/sgp4`): Гаусс–Ньютон по переменным без особенностей
  классических углов, производные — разностями самой теории. По положениям самой теории
  набор возвращается: низкая орбита за двое суток вместе с B* — элементы до 10⁻¹⁵, B* —
  шесть цифр, невязки 5·10⁻⁸ м (8 шагов от оскулирующих элементов); эксцентрическая за трое
  суток и 12-часовая (ветвь дальнего космоса) за четверо — так же.
- **Многократная стрельба и продолжение семейств** (`myb_cr3bp_orbit_from_state`,
  `myb_cr3bp_orbit_correct`, `myb_cr3bp_orbit_continue` в `myb/cr3bp.h`). Орбита разрезана на
  равные по времени части; неизвестные — состояния в разрезах и период; условия — стыковка
  частей (одну составляющую замыкания даёт интеграл Якоби) и фаза. Симметрия не
  предполагается; шаги — минимальной нормы (`myb_shoot`). Продолжение — псевдодлиной дуги:
  касательная семейства есть нуль-вектор якобиана условий. Орбита Ляпунова L1 каталога JPL —
  неподвижная точка; сбитая на 2·10⁻⁵ во всех разрезах возвращается к замыканию 2·10⁻¹⁰; 25
  шагов по семейству: каждый член замыкается до **4·10⁻¹³** и совпадает с корректором,
  который предполагает симметрию, до 7·10⁻¹⁷ по состоянию и 3·10⁻¹⁴ по периоду.
- **Вариационные уравнения с DOP853 в `myb_orbit`** (остаток долгов 12–17): вариации идут
  частью одной системы первого порядка под теми же допусками; матрица перехода за 5 витков —
  3·10⁻¹¹ от замкнутой формы; импульс её не меняет.
- **Малая тяга: закон Q-law** (`myb_qlaw`, `myb_qlaw_direction`, `myb_qlaw_arrived`,
  `myb_term_qlaw` в `myb/thrust.h`; Petropoulos 2004). Q — мера расстояния до целевой орбиты
  (расстояние по каждому элементу, делённое на наибольшую скорость его изменения где-либо на
  орбите); тяга направлена туда, где Q убывает быстрее всего, — градиент Q, проведённый через
  уравнения Гаусса. Ни оптимизации, ни начального приближения не нужно. Подъём 7000 → 10 000
  км: **1234,3 м/с против 1232,6 у Эдельбаума** (0,14 %) за 14,00 суток; с поворотом плоскости
  на 0,1 рад — 1746 м/с против оптимума 1641 (на 6 % выше); переход с эллипса e = 0,725 на
  окружность 42 164 км — 26,6 суток, перицентр не ниже 6738 км при пороге 6600. Найдено по
  ходу: двигатель, который горит всегда, у цели **дрожит и перестаёт продвигаться** — в
  100 км от цели, полмиллиона шагов интегратора на сутки: нормированный градиент
  перескакивает там, где проходит через нуль. Лекарство — порог эффективности Петропулоса
  (`myb_qlaw_term.effectivity`): двигатель молчит там, где тяга на этом участке орбиты даёт
  меньше заданной доли лучшего. Член модели не помнит, когда горел, поэтому с порогом он
  завышает расход массы. **Масса в состоянии** (`myb_qlaw_flight_rhs`, `myb_qlaw_fly`):
  седьмая составляющая падает только пока двигатель горит. Тот же переход на 42 164 км:
  26,5 суток, двигатель включён 22,6 из них, **2020 м/с против 2389**, которые насчитал бы
  член без памяти; без пауз масса сходится со скоростью расхода до шага наблюдения. Поле
  без двигателя — точечная масса или любая модель сил.
- **Сближение с ковариациями, которые переносят сами орбиты** (`myb_conjunction_find`).
  Обе орбиты создаются с вариационными уравнениями, ковариации состояний задаются на момент
  старта; в каждом сближении ковариация относительного положения — Φ_r P Φ_rᵀ первой плюс
  второй. Сближение лежит внутри шага, а назад орбита не ходит, поэтому строки положений Φ
  берутся на той же кубике, что и состояния: строки скоростей Φ — их производные. Всё, что
  есть в моделях сил, действует на неопределённость так же, как на движение. Против
  замкнутой матрицы перехода задачи двух тел (4 сближения, шаг 20 с): ковариация —
  **2,5·10⁻⁹**, вероятность — 2,6·10⁻⁹.
- **Непрямой метод** (`myb_indirect_solve`, `myb_indirect_sample` в новом `myb/optimal.h`):
  условия принципа максимума Понтрягина, решаемые стрельбой по сопряжённым переменным в
  начале. Минимум топлива за заданное время — гомотопией от минимума «энергии» (ε = 1,
  гладкая задача) к минимуму топлива (ε → 0, двигатель включён полностью или выключен;
  Bertrand, Epenoy 2002), каждое решение — приближение следующего, с предсказанием по
  секущей в логарифме ε. Неизвестные — семь сопряжённых и множитель стоимости, вместе
  единичный вектор: тогда случайная точка сферы — годное первое приближение (Jiang, Baoyin,
  Li 2012); приближения берутся из фиксированной последовательности, результат одинаков
  везде. Минимум времени — двигатель всегда включён, время прибытия неизвестно, условие —
  трансверсальность для движущейся цели. Поле — точечная масса или модель сил (сопряжённые
  идут через её якобиан). Измерено: переход 7000 → 8000 км с поворотом плоскости на
  0,06 рад за 4500 с при 0,3 м/с² — гамильтониан постоянен до **10⁻¹²…10⁻¹⁶**, промах у цели
  10⁻³ м; минимум энергии оставляет 762,689 кг, минимум топлива — **780,076 кг** (ε = 10⁻⁴,
  14 шагов), двигатель включён 49 % времени и лишь в 0,2 % отсчётов не на упоре. При
  1 м/с² по полуэллипсу Гомана — **486,84 м/с против 486,82** двух импульсов. Минимум
  времени до цели на окружности 8000 км — 3633,451 с, функция переключения всюду
  отрицательна; минимум топлива за это же время тратит те же 363,345 кг, а за время на 3 %
  короче решения нет. Найдено по ходу: (1) компланарный переход между близкими
  окружностями почти вырожден — расход почти не зависит от того, где работает двигатель
  (486,8 м/с у Гомана и 487,4 у спирали), гомотопия на нём останавливалась на ε = 4·10⁻⁴;
  добавлено предсказание по секущей, а оборванный путь возвращает последнее найденное
  решение и его ε; (2) приближения, которые приводят к решению, начинают медленно —
  невязка 0,2…0,9 после десяти шагов Ньютона, — поэтому отбраковывать их рано нельзя.
- **Решатель нелинейных программ** (`myb_nlp_solve`): равенства, неравенства и границы
  переменных, до 256 неизвестных, плотные матрицы. Метод множителей (расширенный
  лагранжиан; схема Birgin и Martínez), внутри — квазиньютоновский шаг с демпфированной
  матрицей BFGS Пауэлла в свободных переменных и проекцией на границы (Bertsekas 1982).
  Задача 71 Хока и Шитковского: f = 17,0140173, x до 7·10⁻⁹, множители 0,16147 и 0,55229;
  7 обновлений множителей, 108 вычислений функции. Долина Розенброка за стеной — точно на
  стене; линейная программа — в вершине.
- **Sims–Flanagan** (`myb_sims_flanagan_mismatch`, `myb_sims_flanagan_solve`): тяга сегмента
  заменена импульсом в его середине, между импульсами — коники; первая половина идёт от
  старта, вторая назад от прибытия, в середине они должны встретиться. Масса берётся в
  середине сегмента: тогда расход линеен по дросселям, и условие на массу в точке встречи
  исчезает — остаются шесть. Неизвестные решателя — величина дросселя от 0 до 1 и два угла
  направления: выключенный двигатель оказывается границей, а не изломом функции. Якобиан
  невязки против разностей — 9·10⁻⁸. Тот же переход, что в непрямом методе: 30 сегментов —
  **220,176 кг против 219,924** (+0,11 %), 13 сегментов на полной тяге и 13 выключены; 60
  сегментов — 219,961 кг (+0,02 %). Прежняя запись, что непрямым методам нужен решатель с
  неравенствами, была неверна: он нужен только Sims–Flanagan.
- **Квазипериодические орбиты** (`myb_cr3bp_torus_from_orbit`, `myb_cr3bp_torus_continue`,
  `myb_cr3bp_torus_state` в `myb/cr3bp.h`): тор как инвариантная окружность потока за время
  T — кривая, которую поток переводит в себя с поворотом на угол ρ (Gómez, Mondelo 2001;
  Olikara, Scheeres 2012); поворот — через тригонометрический интерполянт на нечётном числе
  точек. Уравнение инвариантности содержит на два условия меньше, чем кажется: поток
  сохраняет интеграл Якоби и действие замкнутой кривой ∮p·dq. Их место занимают два
  множителя при градиентах этих инвариантов (матрица симплектической формы в координатах
  x, v выведена из уравнений движения); в решении множители равны нулю, а их остаток
  показывает, хватает ли точек. Две фазы закрепляют точки вдоль окружности и вдоль потока;
  одно условие выбирает семейство (постоянная Якоби, T или ρ), по нему — псевдодлина дуги.
  Первое приближение — собственный вектор матрицы монодромии для пары на единичной
  окружности. Измерено: у устойчивой удалённой ретроградной орбиты каталога JPL окружность
  из 21 точки возвращается на себя за 20 оборотов до **3,7·10⁻¹¹** (интегратор проверки —
  другой, DOP853), множители — 10⁻¹⁵, постоянная Якоби по окружности — 4·10⁻¹⁵; четыре шага
  по семейству до размера 0,02 — 1,3·10⁻¹⁰; шаг вдоль семейства и обратно — 1,1·10⁻¹¹; обе
  пары орбиты дают торы — из плоскости и в ней. Лиссажу: у малой орбиты Ляпунова L1 (38 км)
  ρ = 0,1764423 против 0,1764459 линейного движения; у орбиты в 4500 км (неустойчива, 2400
  раз за оборот) тор выходит на **3617 км** из плоскости и возвращается за оборот до
  1,6·10⁻¹¹. Для систем больше 64 неизвестных LU вынесен во внутреннюю функцию без
  ограничения порядка.
- **Отнесено дальше**: двойная итерация по r, методы Лапласа и Гудинга для определения
  орбиты — фаза 22 (те же входные данные, что у Гаусса; нужны для дуг, где направления
  почти компланарны); вероятность длительного сближения (нелинейное относительное
  движение) — фаза 22; в оптимальной малой тяге — выход на орбиту со свободной фазой
  (сейчас только встреча с заданным состоянием), поле модели сил в Sims–Flanagan (сейчас
  точечная масса), цепочки участков с пролётами — фаза 22; устойчивость торов и их
  многообразия — фаза 22; верхние слои привязок для нового интерфейса — фаза 21.
- **Проверено** (2026-11-11): Windows — `windows-release` 100 тестов из 100, четырнадцать
  затронутых при -O0 (с проверкой стека и запретом libm), двенадцать под UBSan; Gentoo
  (Clang 21.1.8) — `linux-release` 100 из 100, сборка без предупреждений, тот же хеш и те же
  цифры решателей; тринадцать затронутых тестов под `linux-asan` — без замечаний.
- **Воспроизводимость**: нагрузка всей фазы — в том числе полёт по Q-law с паузой,
  перенесённые ковариации, обе задачи непрямого метода, Sims–Flanagan, задача 71 и тор с
  шагом по семейству; эталон `0xb22481187ba3923a`, один при -O0 и -O2;
  `MYB_REPRO_PREFIX=18` сверяет `0xed85437b94d0e024`. Проверки решателей берут синус и

### Решения фазы 18

- **Система тел с моделями** (`myb/system.h`, `myb_system`). Точечные массы остаются у
  `myb_nbody` внутри — с его графом, членами 1PN, потоками и теми же битами; над ними каждый
  уровень называется явно:
  - *поле* (`myb_system_add_field`): фигура тела действует на другое тело как на точку, та
    действует обратно (импульс сохраняется) и поворачивает тело. Против той же суммы,
    собранной вручную, — те же биты; импульс — 2·10⁻¹⁶;
  - *фигуры* (`myb_system_add_figures`): квадруполи двух тел друг на друга, с моментами;
  - *прилив* (`myb_system_add_tide`, `myb_system_set_tide`): прилив, поднятый одним телом на
    другом, действует на третье или на само поднявшее;
  - *искажение* (`myb_system_add_distortion`): тело с интегрируемым вращением искажается
    чужим приливом и собственным вращением;
  - *пара PN* (`myb_system_add_pn_pair`) и *действие* (`myb_system_add_action`) — ниже.
- **Прилив по полосам с запаздыванием** — модель эфемерид JPL (Folkner и др. 2014, ур. 31–32):
  числа Лява k₂ⱼ долгопериодной, суточной и полусуточной полос, у каждой своё орбитальное
  запаздывание (где было поднимающее тело) и вращательное (на какой угол тело повернулось).
  Потенциал записан по полосам, U ∝ Σ k₂ⱼ Wⱼ(r, r*ⱼ)/|r*ⱼ|⁵, при равных k₂ⱼ это
  k₂ G m R⁵ P₂/(r³ r*³); ускорение — его градиент, реакция — на тело. Прежнее положение
  берётся из движения в данный момент: ряд Тейлора до третьего порядка (ускорение точечных
  масс и рывок пары) — история не хранится. Против градиента разностями — 7·10⁻¹¹; прежнее
  положение против кеплерова движения — 3·10⁻¹¹; запаздывающая часть против формулы Миньяра
  первого порядка (`myb_force_tidal_lag`) — 5·10⁻³ при угле запаздывания 4·10⁻³.
- **Вращение, интегрируемое вместе с движением** (`myb_system_set_rotation`): мантия, в
  которой может быть жидкое ядро, — модель Луны из тех же эфемерид. Кватернион взят
  координатой второго порядка, q″ = (q′ω + qω′)/2 с ω = 2 q̄ q′, а угловая скорость ядра —
  скоростью вспомогательной координаты, поэтому **IAS15 интегрирует движение и вращение одной
  системой**, без отдельного интегратора первого порядка. Тензор инерции мантии искажается
  приливом (положение тела и система мантии — запаздывающие) и вращением; степень 2 поля
  такого тела берётся из тензора инерции. Свободный волчок за 30 суток — **3·10⁻¹³** от
  точного решения, |q| − 1 = 5·10⁻¹⁵; тело, которое поворачивает точечная масса: орбита и
  вращение обмениваются 4·10⁻⁵ момента, их сумма сохраняется до **4·10⁻¹⁶**.
- **Производная вращательной деформации** (остаток фазы 9). Скорость изменения
  вращательной части тензора линейна по искомой ω′: d/dt[f(ωωᵀ − ω²/3)]ω = f(ω²ω′ + ω(ω·ω′)/3),
  поэтому уравнение мантии решается как (I + K)ω′ = …. Измерено на Луне: ориентация меняется
  на 0,0003″ за 5 лет, положение — на 1 см; оценка «на порядки меньше моментов»
  подтвердилась, но член в модели оставлен.
- **Группы координат в IAS15** (`myb_ias15_options.groups`, `myb_system_integrator`).
  Критерий шага и сходимости итерации берёт максимумы по блокам **всего** состояния; рядом
  с ускорениями в м/с² вторые производные кватерниона (1/с²) не видны вовсе — шаг выбирала
  одна орбита, и волчок расходился (|q| − 1 = 10³). С группами (положения всех тел; каждое
  вращение; каждая пара спинов) каждая судится по себе, берётся кратчайший шаг и худшая
  сходимость. Без групп — прежние биты (хеш воспроизводимости не изменился).
- **DE440 заново** (`test_de440_system`) — критерий фазы. Из эфемериды взято только состояние
  на JD 2440400,5 (положения — из `de440.bsp`, углы и угловые скорости Луны и её ядра — из

  поле Луны до степени 6 на Землю или Луну, Солнце, Меркурий, Венеру, Марс и Юпитер;
  квадруполи Земли и Луны; приливы Земли от Луны и Солнца на Луну с пятью запаздываниями
  DE440; вращение Луны с ядром. Расхождение с DE440:

- **Сближения, столкновения, слияния** (`myb_system_set_radius`, `myb_system_advance`,

### Привязки: C++, Python, Rust

Сделаны после долгов фаз 12–17 (каталог `bindings/`). Общая схема одна на три языка — два слоя:

- **нижний — весь C-интерфейс**, без ручной работы: в C++ это сами заголовки (они уже
  совместимы с C++17); в Python — объявления, которые даёт препроцессор из тех же заголовков;
  в Rust — объявления bindgen. Ни одной функции не пропущено, расхождение с заголовками
  ловится тестом;
- **верхний — в манере языка**, над путём, которым идёт большинство программ: ядра и шкалы
  времени, эфемериды SPK, поле тяготения, окружение, модель сил с готовыми членами,
  распространение, события, импульсы, матрица перехода, сообщения OEM в обеих нотациях. Он
  даёт владение (объект библиотеки освобождается сам; модель сил удерживает окружение, поля
  и структуры своих членов), ошибки в манере языка и вызываемые объекты языка вместо
  указателей на функции. Остальное (N тел, оценивание, CR3BP, наведение, ориентация,
  наблюдаемые, писатели SPK/PCK/SP3, …) берётся нижним слоем: слои смешиваются свободно.

В привязках **нет арифметики**: число, полученное через них, имеет те же биты, что и те же
вызовы на C. Это и проверяется: орбита примера `examples/low_orbit.c` (поле с J2 и
сопротивление, сутки, 15 восходящих узлов, 776 шагов), собранная из классов каждой привязки,
даёт моменты узлов и конечное состояние **бит в бит** с вызовами C.

- **C++** (`bindings/cpp/include/myb/myb.hpp`, цель CMake `myb::cpp`, C++17, только
  заголовок). Исключений нет: функция, которая может не удаться, возвращает
  `myb::result<T>` — статус, сообщение разборщика и значение; запрос значения у неудачного
  результата — нарушение контракта и останов с сообщением, как `MYB_CHECK` в библиотеке.
  Классы `kernel_pool`, `time_system`, `ephemeris`, `gravity_field`, `environment`,
  `force_model`, `orbit`, `ephemeris_message`; члены модели и события — лямбды. Обработки
  исключений в заголовке нет вовсе — ничего не бросается и не ловится, он собирается с
  `-fno-exceptions`: лямбда сообщает о неудаче статусом, а исключение, вышедшее из неё,
  завершает программу (она вызывается из C через функцию `noexcept`; обе такие функции
  стоят в `myb::detail` рядом со `static_assert(noexcept(…))`, так что снять `noexcept`
  незаметно нельзя — заголовок перестанет собираться).
  Тест `test_cpp_binding` — 123 проверки под теми же предупреждениями, что и библиотека;
  пример `examples/low_orbit.cpp` собирается против установки, статической и разделяемой
  (`test_install`).
- **Python** (`bindings/python`, пакет `myb`, cffi в режиме ABI — компилируемой части нет,
  пакет загружает разделяемую библиотеку). Объявления `_cdef.h` (2171 строка) пишет
  `tools/make_cdef.py`: препроцессор Clang над заголовками с пустыми `stddef.h` и `stdint.h`
  — получается только своё, одинаковый текст на любой системе; тест перегенерирует и
  сравнивает. `myb.lib` и `myb.ffi` — весь интерфейс; классы `KernelPool`, `TimeSystem`,
  `Ephemeris`, `GravityField`, `Environment`, `ForceModel`, `Orbit` и функции. Ошибка —
  исключение `myb.Error` со статусом библиотеки. Исключение, поднятое в функции Python,
  которую вызвал код C (член модели, провайдер, событие), запоминается, обратный вызов
  сообщает о неудаче, и исключение поднимается из того вызова библиотеки, который шёл.
  Библиотеки `ext/` — по запросу: `myb.extension("sgp4")`. Библиотека ищется по
  `MYB_LIBRARY`, в `_lib/` пакета и системным поиском. Тест `test_python_binding` — 14 тестов.
- **Rust** (`bindings/rust`: крейты `myb-sys` и `myb`; ни один не зависит от чужих крейтов).
  `myb-sys` — объявления bindgen 0.72, сохранённые в крейте: сборка не требует libclang.
  Они порождены для одной фиксированной цели, чтобы текст не зависел от машины; различия
  платформ идут через `c_long` и `usize`, которые Rust разрешает там, где собирается крейт.
  `build.rs` находит библиотеку по `MYB_LIB_DIR` или через pkg-config; по умолчанию
  статическая, с набором MSVC — только разделяемая (статическая собрана для ABI GNU).
  `myb` — типы с `Drop`, `Result<T, myb::Error>` со статусом, замыкания `Fn` для членов,
  провайдеров и событий; замыкание сообщает о неудаче через `Err`, а паника не ловится — в
  функции, вызванной из C, она завершает программу; общие объекты — через `Rc`, типы не `Send` (у объектов библиотеки рабочая память на один
  поток). Модули `ext/` — за одноимёнными возможностями (features). Тест
  `test_rust_binding`: 7 интеграционных тестов, 2 теста `myb-sys` (с библиотекой
  `ext/sgp4`), пример в документации; clippy без замечаний. Один из семи запускает сам себя
  вторым процессом, в котором замыкание члена модели, а затем события, паникует: процесс
  завершается с сообщением «panic in a function that cannot unwind», а не кодом теста,
  упавшего с размоткой стека.
- **Тесты привязок** регистрируются в ctest, когда есть чем их выполнить: компилятор C++,
  Python с cffi (`MYB_PYTHON` задаёт интерпретатор), cargo. Под санитайзерами — только C++.
- **Проверено** (2026-11-11, вместе с якобианами членов поверхности и Ярковского): Windows —
  Clang 23 с libstdc++ 15, Python 3.13 с cffi 2.0, Rust 1.90 (набор GNU), `windows-release`
  94 теста из 94, затронутые тесты при -O0 (с проверкой стека) и под UBSan; Gentoo —
  Clang 21, Python 3.14 с cffi 2.1.1 (из Portage), Rust 1.93, `linux-release` 94 из 94,
  11 затронутых тестов (с `test_cpp_binding`) под `linux-asan`; хеш воспроизводимости
  `0xb76153a8dca45827` на обеих системах. На обеих системах орбита из классов каждой привязки совпадает с вызовами C
  бит в бит, а `test_install` собирает против установки и пример на C++.

### Привязки: что предстоит

- **Haskell** (запрос пользователя 2026-11-11; по его решению — в конце, как и Go: фаза 21).
  Полная привязка по той же
  схеме, что три готовые. Нижний слой — весь C-интерфейс: объявления `foreign import` и
  экземпляры `Storable` структур, порождённые из заголовков (смещения полей считает
  hsc2hs по самим заголовкам, от руки ничего). Верхний — в манере языка над тем же путём:
  объекты с финализаторами (`ForeignPtr`), неудача — значением (`Either` со статусом
  библиотеки), члены модели, провайдеры и события — функции Haskell через
  `foreign import ccall "wrapper"`; модель удерживает то, на что ссылаются её члены. Обработки
  исключений нет, как и в остальных привязках: функция сообщает о неудаче статусом. Арифметики
  нет — орбита примера `examples/low_orbit.c` должна совпасть с вызовами C бит в бит. Пакет
  cabal над статической библиотекой (GHC на Windows — тоже набор mingw-w64; совпадает ли его
  рантайм C с тем, под который собрана библиотека, выяснится при реализации, запасной путь
  — разделяемая библиотека), тест в ctest, когда есть GHC и cabal; на Gentoo они ставятся из
  Portage и остаются. К фазе 21 фазы 18–20 перестанут менять интерфейс, и верхний слой
  пишется один раз.
- **Go** (вердикт 2026-11-11, фаза 21). Обычный cgo, статическая `libmyb.a` через
  pkg-config, только крупный слой: один переход в C — одна задача (распространить орбиту,
  найти события, подогнать, прочитать или записать файл). Цена перехода (десятки
  наносекунд) не зависит от работы внутри, поэтому модель собирается данными, а всё «на
  эпоху» и «на точку» идёт одним вызовом над срезом. Недостающие массовые формы
  (эфемериды, повороты, время, Кеплер) добавляются в саму библиотеку на C — от них выиграет
  и Python. Функции Go как члены модели и события — отдельный, явно медленный путь. Полного
  нижнего слоя нет: типы cgo не выходят за пределы своего пакета. purego не годится
  (структуры по значению не на всех платформах, обратные вызовы не возвращают `double`),
  порт на Go — тоже (компилятор вправе сливать `x*y + z` в FMA).
- **Верхние слои для остального интерфейса** (фаза 21): N тел, оценивание, CR3BP,
  наведение, ориентация, наблюдаемые, писатели файлов — во всех привязках сразу, когда фазы
  18–20 закончат менять эти части.
- **Публикация** (фаза 21, после тега): PyPI и crates.io — вместе с vcpkg и Conan; нужны
  учётные записи пользователя.
- **Чего привязки пока не проверяют** (фаза 21): потребители с MSVC — заголовок C++ под `cl`
  и набор Rust MSVC через DLL (нужна библиотека импорта `myb.lib`; на машине разработки
  компоновщика MSVC нет); macOS; тесты Python и Rust под санитайзерами.

**Решение пользователя 2026-11-11: ни от одного пункта не отказываемся**

Пять пунктов я предлагал снять — по соотношению труда и пользы и потому, что часть из них

  Разностями модели не остался ни один готовый член.
- **Газовыделение с запаздыванием** (`myb_force_nongrav_delayed`, `myb_nongrav_term.delay`):
  g берётся в точке кеплеровой орбиты на `delay` секунд раньше (Yeomans & Chodas 1989). Через
  2·10⁶ с после перигелия ускорение равно перигелийному без запаздывания (2,579·10⁻⁸ м/с²).
- **Эффект Ярковского проводящего тела** (`myb_yarkovsky.conductivity`,
  `myb_yarkovsky_response`): отклик сферы на периодический нагрев 1/(1 + λζ(z)),
  ζ = z j₁′(z)/j₁(z) — решение линейной теплопроводности; при радиусе меньше 0,3 глубины
  тепловой волны — ряд до z¹² (замкнутая форма теряет там восемь цифр). Против mpmath —
  5·10⁻¹³ на всём диапазоне размеров. Зерно 2 мм: суточный дрейф обнуляется, как и должен.
  Суточная сила в любой точке любой орбиты — `myb_force_yarkovsky`, член `myb_term_yarkovsky`.
- **Сезонный эффект на эксцентричной орбите** (`myb_yarkovsky_season`,
  `myb_force_yarkovsky_season`, поле `season` члена): нагрев вдоль оси вращения —
  ряд Фурье по средней аномалии; каждая гармоника k отвечает с откликом тела на частоте kn
  (линейная теория Вокроуглицкого и Фаринеллы 1999). Гармоник столько, чтобы члены упали до
  10⁻¹⁴ первого: 2 на окружности, 38 при e = 0,3, 111 при 0,6, 551 при 0,85; предел
  e ≤ 0,95. Против mpmath (25 знаков, другое число узлов квадратуры, отклик через функцию
  Бесселя): ускорения — **8·10⁻¹⁴**, средний дрейф — **4·10⁻¹³** на орбитах до e = 0,85; на
  окружности дрейф совпадает с замкнутой формой до 5·10⁻¹⁵.
- **YORP с теплопроводностью** (`myb_force_yorp`): момент, усреднённый по обороту, с запаздыванием
  температуры граней по тепловому параметру Θ. Осевая составляющая **не зависит от Θ**
  (−2,1924·10⁻³ pR³ при Θ = 0, 1 и 30) — результат Чапека и Вокроуглицкого 2004; поперечные
  меняются в разы.
- **Момент прилива** (`myb_torque_tidal_lag`): момент на тело от того же запаздывающего
  прилива, в единицах `myb/attitude.h` — для изменения его вращения.
- **Косвенный член сплюснутости** (`myb_term_field_indirect`): ускорение начала координат
  (центрального тела) от притяжения его фигурой возмущающих тел. Земля и Луна:
  −1,4834·10⁻¹¹ м/с², как J2 в замкнутом виде.
- **Тень нескольких тел сразу** (`myb_shadow_fraction_many`, до 8): на каждой окружности диска
  источника вычитается **объединение** дуг, закрытых телами, с разрезами на лимбах и на
  пересечениях их окружностей. Против подсчёта точек диска — 1,7·10⁻⁶; произведение долей,
  которое считалось раньше, ошибается на 7·10⁻² (а когда два тела вместе закрывают диск
  целиком — даёт 0,15 вместо нуля). В членах модели: одно тело на диске — прежнее
  произведение (те же биты), два и больше — объединение.
- **Рефракция в атмосфере затеняющего тела** (`myb_refraction`, `myb_refraction_bending`,
  `myb_shadow_fraction_refracted`; поле `atmospheres` членов давления): каждый элемент диска
  виден под углом, смещённым изгибом луча α(h) = (n − 1)√(2π(R + h)/H), с весом сжатия
  изображения и поглощением по пути. Луч, касающийся Земли, изгибается на 65,7′ (две
  горизонтальные рефракции по 34,5′); при исчезающей атмосфере доля — безвоздушная до
  3·10⁻¹⁰; без поглощения свет только перераспределяется: недостающий поток за Землёй в
  единицах её сечения — 1,000559 против 1,000554 для лучей, упёршихся в поверхность. В
  6000 км от оси, внутри безвоздушной тени, чистый воздух оставляет 2,2 % света.
- **Переходный режим обтекания** (`myb_gas_knudsen`, `myb_gas_bridge`; поля `length`,
  `molecule`, `continuum_cd` члена сопротивления поверхности): доля свободномолекулярного
  режима sin²(π(3 + lg Kn)/8) между Kn = 10⁻³ и 10. Воздух на 100 км: пробег 0,14 м, тело
  2 м — Kn = 0,069, доля 0,44.
- **Другие интеграторы в `myb_orbit`** (`myb_orbit_options.integrator`): DOP853 с теми же
  состояниями на запрошенные моменты, событиями и разрывами шага (два тела за 5 витков —
  7·10⁻⁴ м, 289 шагов). RKN12(10) не подключён: у него нет плотного вывода своего
  порядка и он требует сил, не зависящих от скорости (плотный вывод для него — фаза 22, см.
  «Старые долги»). Вариационные уравнения — только с IAS15 (`MYB_E_DOMAIN` иначе); с DOP853
  — фаза 19.
- **Копия окружения для потока** (`myb_env_clone`): те же тела и провайдеры, свои таблицы и
  кэш момента.

### Решения фазы 17

- **Свет на движущемся объекте** (`myb_force_radiation_moving`; `myb_radiation_term.moving`):
  члены первого порядка по v/c — аберрация и доплеровское смещение (Burns, Lamy, Soter 1979,
  ур. 2); часть вдоль −v — торможение Пойнтинга–Робертсона. Пылинка с β = 0,2 на орбите
  e = 0,3 за 20 витков: a убывает на 7,272665·10⁻³ а. е., e — на 2,190050·10⁻³; усреднённые
  уравнения Уайатта–Уиппла, проинтегрированные за то же время, дают **те же семь цифр**.
  Якобиан члена с движением — аналитический (2·10⁻¹⁰ и 10⁻⁹ от разностей).
- **Кометы и астероиды** (`myb_nongrav`, `myb_term_nongrav`): a = g(r)(A1 r̂ + A2 t̂ + A3 n̂) с
  g(r) = α (r/r0)⁻ᵐ (1 + (r/r0)ⁿ)⁻ᵏ. Готовые: сублимация водяного льда Марсдена, Секанины и
  Йоманса (g(1 а. е.) = 1 + 2·10⁻⁹ с десятизначным α каталога JPL) и степенной закон —
  эффект Ярковского в том виде, в каком его подгоняют к астероидам (A2, показатель 2).
  Дрейф при A2 = 10⁻¹⁰ м/с²: 9,681642·10⁻⁴ м/с против 2A2(1−e²)(r0/p)²/n =
  9,681647·10⁻⁴ (5·10⁻⁷); комета с A1 и A2 — 5·10⁻⁶ от уравнения Гаусса, усреднённого по
  орбите квадратурой.
- **Дрейф Ярковского из тепловых свойств** (`myb_yarkovsky_drift`): линейная теория
  Вокроухлицкого для тела, много большего глубины тепловой волны (κ₁ = κ₂ = κ₃ = ½):
  суточный и сезонный члены. Километровый камень на 2,5 а. е. — 2,2·10⁻⁴ а. е./млн лет,
  наружу при прямом вращении; проверены знаки, пределы, масштаб по радиусу и максимум при
  тепловом параметре √2.
- **Отдача излучения** (`myb_force_emission`, `myb_term_recoil`): тепло РИТЭГ и приборов,
  луч антенны — мощность в направлении, закреплённом в теле объекта, с затуханием по
  экспоненте (распад, прекращающееся газовыделение). 63 Вт на 241 кг — 8,72·10⁻¹⁰ м/с²
  (аномалия «Пионеров» 8,74·10⁻¹⁰).
- **Запаздывающий прилив** (`myb_force_tidal_lag`, `myb_term_tidal_lag`): модель Миньяра с
  постоянной задержкой — ускорение спутника относительно тела от прилива, который он сам
  поднимает; вращение тела берётся из его ориентации. da/dt = 6 k₂ Δt (m/M)(R/a)⁵ n a (Ω − n):
  для Луны (k₂ = 0,3, 600 с) **3,79 см/год**; интегрирование десяти витков — 28,348358 м
  против 28,348364 м формулы; при обратном вращении орбита сжимается; синхронная орбита —
  ноль.
- **Поверхность объекта** (`myb/surface.h`):
  - **закон ориентации** — функция, дающая матрицу «инерциальные оси → тело объекта» по
    времени и состоянию; готовые: постоянная, орбитальная (радиус, трансверсаль, нормаль),
    рыскание навигационного спутника (z к телу, y поперёк Солнца), равномерное вращение;
  - **свободномолекулярное обтекание** (`myb_force_gas_plates`): формулы Сентмана в записи
    Доорнбоса — сопротивление и подъёмная сила каждой пластины, включая отвёрнутые от потока,
    с аккомодацией энергии и температурой стенки. Пластины, разложенные по сфере
    квадратурой, дают **замкнутую формулу сферы до 5·10⁻¹⁵** и нулевую подъёмную силу (до
    2·10⁻¹⁵) при отношениях скоростей от 0,3 до 31 — две формулы проверяют друг друга (их
    согласие до 10⁻³⁰ проверено в mpmath до кодирования); C_D сферы на 7,6 км/с в атомарном
    кислороде при 900 К — 2,41;
  - **свет на сетке с самозатенением** (`myb_force_radiation_mesh`): каждая грань — пластина;
    при `shadows = k` грань делится на k² равных треугольников, и часть освещена, только
    если луч от её центра к источнику не встречает сетку (`myb_polyhedron_ray`, фаза 16).
    Куб перед плитой 3×3 м: освещённая площадь **9,000000000000 м²** — ровно силуэт; куб
    как сетка и как шесть пластин — 10⁻¹⁶; гранёная сфера с ламбертовым переизлучением —
    0,995 от (1 + 4/9)πR²p при 1280 гранях;
  - **YORP**: та же функция с чисто тепловой поверхностью — модель нулевой теплопроводности
    Рубинкама, она возвращает и момент. Момент вдоль оси, усреднённый по обороту: у
    симметричного тела 6·10⁻¹⁷, у тела с «лопастями» −6,2190·10⁻³ p R³, у его зеркального
    отражения **+6,2190·10⁻³** — знак меняется, величина совпадает до 10⁻¹²;
  - члены модели: свет на пластинах или сетке с ориентацией и тенями тел
    (`myb_term_surface_radiation`: чёрная пластина лицом к Солнцу = сфера с c_r = 1 до
    4·10⁻¹⁶), газ на пластинах с ветром (`myb_term_surface_drag`).
- **Ветры** (`myb_wind_function`, поле `wind` члена сопротивления): скорость газа
  относительно вращающегося тела; ветер «на восток пропорционально расстоянию от оси»
  совпадает с более быстрым вращением атмосферы до 10⁻¹⁴.
- **Переменная масса** (`myb_object.mass_function`): члены поверхности берут массу на момент
  t; `myb_thrust_mass_at` связывает её с дугами тяги — свет сильнее толкает то, что осталось
  после сжигания топлива (отношение ускорений = отношению масс до 10⁻¹⁴).
- **Импульсные манёвры** (`myb_orbit_kick`): скорость меняется скачком в достигнутый момент,
  интегратор запускается заново. Вариационные уравнения линейны по Φ и S, поэтому они

### Решения фазы 16

- **Разрывы шага** (`myb_force_model_add_break`, `myb/model.h`). Сила на краю тени непрерывна,
  но не гладка, и шаг IAS15, накрывший край, теряет порядок: ошибка перестаёт убывать с ε.
  Разрыв — функция g(t, y) того же вида, что событие; объявляется **модели сил**, а не
  распространителю, поэтому его видят и `myb_orbit`, и оцениватель, и фильтр. После шага
  функции разрывов просматриваются на его плотном выводе (как события: четыре части шага,
  корень — на многочлене шага); шаг, содержащий смену знака, **отзывается и берётся заново
  от своего начала ровно до корня** (`myb_internal_ias15_retake`): предсказанием служит
  многочлен отозванного шага на оставленной части, так что повторный шаг сходится за
  один-два прохода, а следующий за краем стартует с того же многочлена, продолженного за
  край. Интегратор не перезапускается: состояние, Φ и S просто продолжаются. Знак каждой
  функции запоминается, поэтому один край не находится дважды.
  - Первый вариант — холодный перезапуск интегратора на каждом крае с композицией Φ и S —
    давал ту же точность, но стоил +70 % времени подгонки LAGEOS (352 перезапуска на
    пропагацию, каждый с отвергнутыми первыми шагами); отзыв шага стоит +26 %.
  - Проверка: орбита 12 000 км с парусностью 0,2 м²/кг, двое суток, 54 края тени. Разброс
    конечного положения при ε = 10⁻⁹…10⁻¹²: **6,4 м без разрывов, 8·10⁻⁷ м с ними**. Φ через
    восемь краёв против разностей целых пропагаций — 7·10⁻⁸ при наибольшем элементе 25;
    ∂x/∂c_r — 2·10⁻⁷ м из 49 м.
- **LAGEOS не зависит от точности интегратора**: края теней Земли и Луны объявлены модели
  (`myb_term_radiation_breaks`), 176 краёв за неделю, 2290 шагов вместо 2177. Невязка
  начального приближения — **25,9587 м при ε = 10⁻¹⁰, 10⁻¹¹ и 10⁻¹²** (без разрывов 25,9520 м
  при 10⁻¹⁰ и 25,9582 м при 10⁻¹²); после подгонки 2,05 см при любом ε. Находка фазы 14
  закрыта.
- **Готовые события** (`myb/events.h`) — функции для `myb_orbit_event` с контекстом-структурой:
  скорость изменения расстояния до тела (апсиды, тесные сближения), расстояние, плоскость
  (узлы), высота над эллипсоидом тела, угол места над станцией, край тени
  (`myb_event_eclipse` на `myb_shadow_margin`: касание дисков снаружи и изнутри — те самые
  моменты, где сила света теряет гладкость), поверхность многогранника. Тела — из окружения

  провайдера она даёт NaN, это не смена знака.
  - Против замкнутых формул на эллипсе e = 0,3: апсиды 2·10⁻¹¹ с, узлы и сфера 10⁻¹² с;
    высота в момент события — 10⁻⁹ м от порога, угол места — 2·10⁻¹⁴ рад (против

  - **Затмения против CSPICE N0067**: SPK пишет сам тест (`myb_spk_writer`, фаза 15), `gfoclt_c`

- **Геометрия поверхности** (`myb/geometry.h`), в связанной системе тела:
  - луч и трёхосный эллипсоид (`myb_ray_ellipsoid`): в координатах, делённых на полуоси,

    методом Ньютона от нижней границы — функция выпукла и убывает, итерация монотонна и не

- **Воспроизводимость**: нагрузка фазы 16 (геометрия, орбита через тень с разрывами и

### Решения фазы 15

- **Печать чисел** (`myb_format_double`, `myb_format_fixed`, `myb_format_scientific`;
  `myb/io.h`) — обратная к `myb_parse_double` и такая же точная: каждая цифра выводится
  целочисленной арифметикой над точным значением числа (длинные целые, порождение цифр по
  Стилу и Уайту), без `printf`, среды выполнения C и локали. Три вида: кратчайшая запись,
  которую `myb_parse_double` читает в то же число (как `repr` в Python); заданное число
  знаков после запятой (до 60); заданное число значащих цифр с показателем (до 60) —
  округление точного значения к ближайшему, половина к чётному. Против CPython на 6124
  значениях — **ни одного расхождения ни в одном виде**; 200 000 случайных чисел читаются
  обратно в те же биты.
- **Запись SPK** (`myb_spk_writer`, `myb/kin.h`): сегменты типов 9 и 13 из состояний на эпохи
  (Лагранж и Эрмит), типов 2 и 3 — многочлены Чебышёва через состояния провайдера в узлах
  Чебышёва на равных частях интервала, с отчётом о наибольшем отклонении между узлами (по
  нему выбирают степень и число частей). Файл DAF: запись файла, цепочка записей сводок и
  имён (по 25 сегментов), данные; little-endian; в буфер или в файл
  (`myb_platform_write_file` — единственное новое обращение к ОС). Файл из 34 сегментов
  читает **CSPICE N0067: положения 3,9·10⁻¹⁶, скорости 1,1·10⁻¹³** от собственного читателя;
  состояния типов 9 и 13 на своих эпохах возвращаются до 1,8 ulp длины вектора; тип 2
  степени 12 на 1000 с — 6·10⁻⁸ м от орбиты.
- **Сообщения CCSDS** (`myb/ccsds.h`; CCSDS 502.0-B-2/B-3, запись «ключ = значение»): OEM —
  чтение (заголовок, сегменты с метаданными, состояния и ускорения, обе формы эпохи; разделы
  ковариации пропускаются; обязательные ключи проверяются; ошибка называет строку) и запись;
  OPM и OMM — разбор в структуру и запись. В файле км, км/с, градусы, км³/с², в API — СИ;
  средние элементы OMM хранятся в единицах каталога, как написаны: они осмысленны только
  вместе со своей теорией. **Число пишется кратчайшей десятичной записью в единицах файла,
  которую читатель превращает в то же значение СИ**: из частного и двух его соседей берётся
  самое короткое из тех, что умножением возвращают исходное число. Поэтому сообщение,
  прочитанное и записанное, сохраняет числа как были («7000» остаётся «7000», а не
  «7000.000000000001»), а записанное и прочитанное возвращает состояния точно — кроме тех,
  которых умножением на 1000 не достичь ни из какого числа километров: 183 из 12 000
  случайных (1,5 %), они отличаются на 1 ulp. Секунды эпох — столько знаков, сколько нужно,
  не меньше трёх; эпохи возвращаются бит в бит.
- **SP3** (`myb_sp3_write`, `myb/kin.h`): SP3-c и SP3-d из описания (спутники, эпохи,
  положения, скорости, пропуски); неделя GPS, секунды недели и MJD заголовка — из первой
  эпохи. Выдержка ILRS по LAGEOS-1, прочитанная и записанная: **258 720 символов строк
  эпох, положений и скоростей — символ в символ**, как и строки заголовка (списки спутников,
  точности, типы); читатель даёт из записанного файла те же биты.
- **TLE** (`myb_tle_format`, `myb_tle_from_omm`, `myb_omm_from_tle`; `ext/sgp4`): две строки
  с контрольными суммами, Alpha-5 выше 99 999; значение, не помещающееся в поле, —
  `MYB_E_DOMAIN`. Все 33 набора проверочного файла Vallado возвращаются в те же значения бит
  в бит, 31 — символ в символ (у двух сам файл отступает от записи каталога: нет типа
  эфемериды; нулевой B* записан как `00000-0`). OMM ⇄ TLE: числа каталога переходят без
  пересчёта, эпоха — календарная дата ⇄ день года.
- **Таблицы чисел** (`myb_table_*`, `myb/io.h`): чтение CSV и родственных записей (запятая,
  точка с запятой, табуляция, пробелы; строка имён; комментарии `#`; пустое поле — NaN) и
  запись кратчайшими записями: 3500 случайных чисел всех порядков — бит в бит.
- **Писатели не выделяют память**: текст идёт в буфер вызывающего, полная длина сообщается
  всегда (`MYB_E_OVERFLOW` — повторить с буфером нужного размера); внутренний писатель
  `src/io/text.[ch]`. Память берут только писатель SPK и читатели.
- **Воспроизводимость**: нагрузка фазы 15 хеширует сами байты — тексты чисел, образ SPK,
  сообщения, SP3, строки TLE, таблицу — и числа, прочитанные обратно; эталон

- **Не сделано**: XML-запись сообщений CCSDS; ковариации OEM и OPM; OCM; запись SPK других

### Решения фазы 14

- **Градиент поля сферических гармоник** (`myb_gravity_field_gradient`, `myb/grav.h`): вторые
  производные потенциала в связанной системе. Вторые производные шаровой функции степени n —
  шаровые функции степени n + 2 (Cunningham 1970; Montenbruck & Gill, ур. 3.33): операторы
  D± = ∂x ± i∂y и Dz сдвигают (n, m) в (n + 1, m ± 1) и (n + 1, m). Пять независимых
  компонент (V_zz, V_xz, V_yz, V_xx − V_yy, V_xy; V_xx + V_yy = −V_zz) — ряды того же вида, что
  потенциал, с коэффициентами степени n + 2 и порядков m, m ± 1, m ± 2; множители полностью
  нормированных функций — √((2n+1)/(2n+5)) на корень из произведения четырёх чисел вида
  n ∓ m + k. Ряды суммируются той же столбцовой рекурсией Холмса–Фезерстоуна, что и потенциал:
  **ни одного деления на cos φ, полюс — обычная точка**, точность — как у потенциала (таблицы
  рекурсии поля продлены на две степени; предел степени для градиента — 2698). Против
  дифференцирования ряда в mpmath (60 знаков; поле степени 8, 32 случая на всех широтах и на
  самих полюсах, разные диапазоны степеней): **2,1·10⁻¹⁵ от наибольшей компоненты, на полюсах
  6·10⁻¹⁶**; против центральных разностей ускорения в поле степени 60 — 2·10⁻¹⁰.
- **Аналитические якобианы членов** (`myb/env.h`, `myb/rel.h`): поле (градиент, повёрнутый в
  инерциальные оси; член сам доводит коэффициенты до момента), давление излучения (на свету
  и в тени — точно, в полутени — разности самого члена), сопротивление (по скорости и
  вращению атмосферы — точно, градиент плотности — разностями функции плотности), Шварцшильд,
  Лензе–Тирринг, де Ситтер (`myb_rel_*_jacobian`). Против центральных разностей: поле
  1·10⁻¹⁰, свет 6·10⁻¹¹, сопротивление 4·10⁻⁸ и 2·10⁻¹¹ (по координате и скорости),
  релятивистские — до 7·10⁻¹¹ (это предел самих разностей). `myb_term_no_jacobian` — нулевой
  якобиан для членов, чей градиент сознательно опускается; `myb_force_model_bind_parameter`
  привязывает параметр к одному члену: его частная производная — разность этого члена, а не
  всей модели (точность 10⁻¹³ вместо 10⁻⁵ у разности суммы с полем и во много раз дешевле).
- **Матрица перехода с полем**: во вращающемся поле степени 8 за два витка матрица из
  аналитического градиента **симплектична до 6·10⁻¹⁷** (с якобианом по разностям — 10⁻¹²) и
  совпадает с разностями целых пропагаций до 5·10⁻¹⁰.
- **Оценивание** (`myb/estim.h`). Неизвестные — состояние на эпоху и параметры модели сил.
  Измерение — функция состояния объекта на момент наблюдения с производными; готовые:
  положение и состояние самого объекта, дальность, скорость дальности, прямое восхождение и
  склонение, азимут и высота от станции на теле окружения (`myb_station`: геодезические
  координаты на эллипсоиде, оси восток–север–зенит). Производные измерений против разностей —
  до 3·10⁻¹⁰.
  - **Наименьшие квадраты по дуге** (`myb_fit_orbit`): Гаусс–Ньютон на вариационных
    уравнениях, нормальные уравнения свободных неизвестных с масштабированием по диагонали
    и разложением Холецкого; закреплённые неизвестные, априорные σ, ковариация, невязки; дуга
    вперёд или назад от эпохи. Без шума смещённое начальное приближение (сотни метров, c_d на
    0,5) возвращается к истине до **2·10⁻⁹ м и 6·10⁻¹¹ в c_d**; с шумом (σ: 1 м, 1 мм/с, 2 мкрад)
    взвешенное СКО 1,035, наибольшая ошибка 1,7 σ собственной ковариации.
  - **Фильтр** (`myb_filter`): расширенный фильтр Калмана на тех же неизвестных, переход
    ковариации через Φ и S, шум процесса как белое ускорение (q·Δt³/3 — проверено: 2,166 м²
    против 2,16), обновление в форме Джозефа. Те же зашумлённые наблюдения по одному от

- **LAGEOS оценивателем библиотеки**: собственный Гаусс–Ньютон теста с разностными частными

### Решения фазы 12

- **Зачем.** Модель сил (`myb/model.h`) складывала члены, которые писал пользователь:
  `test_lageos` и `test_spacecraft` — по 700 строк склейки (ориентация, третьи тела, давление).
  Из привязок это был бы вызов интерпретатора на каждое вычисление ускорения. Теперь модель
  собирается из структур с числами и указателями на провайдеры.
- **Провайдеры** — общая форма, в которой эфемериды и вращение входят в модели:
  `myb_state_function` (перенесён из `observe.h` в `myb/kin.h`; `myb_spk_body` — тело набора
  SPK) и `myb_orientation_function` (`myb/frames.h`: поворот инерциальные оси → система тела
  и, для тела с наблюдаемым вращением, время вращения UT1 и координаты полюса — их требуют
  приливы; готовые: CIP + EOP, бинарный PCK, WGCCRE, постоянный поворот).
- **Окружение** (`myb/env.h`, `myb_env`): тела сценария — у каждого GM, провайдер состояния,
  провайдер ориентации, радиус, светимость, потемнение к краю, момент импульса; всё
  необязательно (это модель тела §3 в том объёме, какой нужен силам). Тело без провайдера
  состояния — начало координат (центральное тело: члены третьих тел получают косвенную
  часть); если провайдер есть у всех — начало инерциальное (барицентр), косвенных членов нет.
  Значения на момент t вычисляются один раз и держатся, пока t не изменится: интегратор
  вычисляет каждый подшаг по нескольку раз, а Солнце нужно шести членам.
- **Шкалы времени.** Время модели — секунды от эпохи на названной шкале; каждый провайдер
  получает тот же момент на своей шкале (TDB для эфемерид JPL, TT для вращения Земли).
  Разность шкал читается из таблицы с шагом по времени модели (по умолчанию час) в узлах
  эпоха + k·шаг, интерполяция Лагранжа по четырём узлам, записанная относительно узла перед t
  (большая постоянная часть разности не вычитается сама из себя). Значение — чистая функция t:
  те же биты при любой истории запросов. Против точного преобразования за ±40 суток:
  **TDB−TT 3,5·10⁻¹⁶ с, TCB−TT (20 с с ходом) 3,1·10⁻¹⁵ с**; ряд из 787 синусов считается
  раз в час, а не на каждое вычисление (это «ускоренный ряд TDB−TT» из списка фазы 7).
- **Готовые члены** — структура контекста и функция вида `myb_term_function`: точечная масса
  и третье тело (с аналитическими якобианами), поле тела в его системе с изменением во
  времени и приливами (для тела не в начале координат — минус то же поле в начале),
  давление излучения источника с тенями тел, излучение планеты, сопротивление во вращающейся
  с телом атмосфере, Шварцшильд, Лензе–Тирринг и де Ситтер, эмпирические RTN (постоянная и
  раз за виток). Объект — `myb_object` (масса, площадь, cr, cd): параметры оценивания — его
  поля и поля структур членов. Атмосфера входит функцией плотности `myb_density_function`;
  в ядре — слоистая экспоненциальная (`myb_exponential_atmosphere`), числа слоёв — данные.
- **Распространение** (`myb/orbit.h`, `myb_orbit`): IAS15 от t0 к t_end своими шагами, каждое
  состояние — из плотного вывода шага, содержащего момент. Шаги не зависят от запрошенных
  моментов (обрезается только последний, по t_end), поэтому **состояние на момент t — те же
  биты, спрошено ли по пути 500 других состояний и событий или ни одного**. События — корни
  g(t, y): знак проверяется на границах четвертей шага, корень уточняется на плотном выводе
  и сдвигается на первое представимое время, где g уже сменила знак, — следующий поиск от
  корня не находит его снова; фильтр по направлению. По запросу — матрица перехода и
  чувствительности (вариационные уравнения `myb/uncert.h`).
- **Проверки.**

    `grav`/`force`/`rel`, вызванных вручную со значениями провайдеров, — **бит в бит** (член —
    не более чем эта композиция); якобиан третьего тела против разностей 2·10⁻¹¹; поле тела

- **Воспроизводимость**: нагрузка фазы 12 (таблица шкал, модель из всех членов с якобианом и

### Решения фазы 11 (после 1.0.0.0)

- **3PN и 3,5PN** (`myb_pn_binary_evaluate`, `myb/rel.h`): коэффициенты A, B относительного
  ускорения из обзора Blanchet (LRR, редакция 2024, ур. calAcoeff, calBcoeff); логарифмы 3PN с
  калибровочной длиной r0′ — параметр (`myb_pn_binary.r0`). Старая функция
  `myb_pn_binary_acceleration` сохранена (без 3PN и спинов). Проверки:
  - **перенос коэффициентов** — против машинного разбора LaTeX-исходника обзора (arXiv:1310.1528,
    sympy, mpmath 40 знаков, 40 состояний): все порядки 1PN…3,5PN до 4·10⁻¹⁶ — опечатка при
    ручном переносе была бы видна;
  - **обобщённый закон Кеплера** Ω²(r) до 3PN с ln(r/r0′) (ур. keplerlaw): коэффициент 3PN
    экстраполяцией Ричардсона до 10⁻⁶ при ν = 0,25 и 0,1, ln = 0 и 2;
  - **радиационное торможение на круговой орбите** (ур. aieom без 4PN-хвоста): поправка
    −743/336 − 11/4 ν — до 4·10⁻⁴ (остаток O(γ));
  - **скорость сближения** ṙ (ур. rOmdot): время сжатия орбиты 200 → 190 Gm/c² против формулы с
    1PN-поправкой −1751/336 − 7/4 ν — 98,7 % поправки (остаток — член 2PN);
  - **инвариант K** на 3PN (Damour–Jaranowski–Schäfer): 135/2 + (−649/4 + 123/32 π²)ν + 7ν² —
    до 0,06 % при ν = 0,25 и 0,1; от r0′ (×1000) не зависит до 10⁻⁴ (а закон Кеплера меняется на
    ~38 x³) — согласованность всех логарифмических членов.
- **Спины** (Kidder 1995; ковариантное условие на спин): спин-орбитальное ускорение (1,5PN),
  спин-спиновое (2PN), квадруполи, наведённые вращением (Poisson 1998; κ = 1 для Керра), и
  прецессия спинов; спины — безразмерные χ = cS/(Gm²), часть состояния (для IAS15 — как
  «скорости» вспомогательных координат). Проверки: предел пробной частицы — ускорение
  Лензе–Тирринга (`myb_rel_lense_thirring`) до 4·10⁻¹⁶; спин-спин + квадруполи — гамильтонова
  система: E и J сохраняются до 10⁻¹⁷; спин-орбита: E_N + E_SO Кидера сохраняется до членов
  второго порядка по спину (×1/10 спина → ×1/100), L_N + L_SO + S — с остатком от прецессии внутри
  L_SO, падающим как 1/r (вне порядка уравнений); соосные спины не прецессируют (точный ноль);
  **PSR J0737−3039B**: геодезическая прецессия 5,0735°/год против формулы Баркера–О'Коннелла
  1,3·10⁻⁵ и предсказания 5,0734°/год (Breton et al. 2008).
- **Плазма** (`myb/observe.h`): столб электронов степенного профиля Σ n_k (R/r)^p_k вдоль отрезка
  (адаптивная Гаусс–Кронрод в угле, видимом из центра; радиальные отрезки — аналитически) и
  групповая задержка 40,308 N/f² (K = e²/(8π²ε₀mₑ) из CODATA 2022, новые константы в
  `codata-2022.tk`). Против mpmath — 6·10⁻¹⁶, против замкнутых форм r⁻², r⁻⁴ — 10⁻¹⁵.
- **Тропосфера** (`ext/troposphere`, цель `myb::troposphere`): модели IERS 2010 гл. 9 по
  опубликованным уравнениям — Саастамойнен (ZHD, ZWD), Мендес–Павлис (оптика), FCULa, VMF1,
  GMF, GPT, градиенты Чена–Херринга; таблицы GMF/GPT — данные из программ IERS (SHA-256). Против
  контрольных примеров программ IERS: FCULa, VMF1 (с высотой и без), GMF, GPT — 10⁻¹⁶…10⁻¹⁵.
  Найдено: опубликованный пример FCUL_ZD_HPA на 1,96·10⁻⁶ меньше в обеих составляющих — общий
  множитель f(φ, H), как будто пример считался с высотой на 7 м меньше; исполнение операторов
  самой программы (с её литералами одинарной точности 0.00266, 3.759) даёт то же отношение —
  пример не соответствует своим входным данным (4 мкм задержки).
- **Ионосфера** (`ext/ionosphere`, цель `myb::ionosphere`): карты IONEX (2D, чтение по формату с
  фиксированными полями, пропуск RMS и карт высот, 9999 → нет данных), интерполяция по описанию
  IONEX (билинейная, во времени — между картами, повёрнутыми с Солнцем), однослойная модель
  (SLM и MSLM CODE) с точкой прокола. Против независимой реализации на Python —
  2·10⁻¹¹ (разрешение MJD в double, 0,6 мкс); точка прокола против пересечения луча с оболочкой
  в декартовых координатах — 9·10⁻¹⁶.
- **Зарядка** (`myb/force.h`): токи OML на сферу для любых сортов частиц с дрейфом (Whipple 1981,
  замкнутые формы через erf/erfc; при M < 10⁻³ — ряд по M²), фотоэмиссия, плавающий потенциал

### Решения фазы 7

- **Сферические гармоники** (`myb/grav.h`): потенциал и ускорение по столбцовой рекурсии
  Холмса–Фезерстоуна (2002) с затравками P̄ₘₘ, масштабированными на 2⁹³⁰ (степень до 2700 на
  любой широте), градиент записан без деления на cos φ (столбцы P̄/u рекурсируются от своих
  затравок) — полюс обычная точка. Коэффициенты — данные: читатель ICGEM (формат 1.0 и 2.0:
  `gfct`, `trnd`, `acos`, `asin`, эпохи `yyyymmdd[.hhmm]`), усечение по степени, система
  приливов файла; `set_time` пересчитывает переменные во времени члены, `add_correction`
  добавляет поправки (приливы) до следующего `set_time`; `clone` — поле на поток. Проверка:
  MPFR 256 бит (потенциал рекурсией высокой точности, ускорение — разностями этого потенциала,
  независимо от формул производных): степень 120 у полюса, рядом с ним, на экваторе —
  4,7·10⁻¹⁶ / 7,5·10⁻¹⁶; степень 2190 на широте 62° (затравки без масштаба ушли бы в
  подпоток) — 4,8·10⁻¹⁶ / 2,5·10⁻¹⁶. Точка, J2 и разбиение по степеням — в замкнутой форме.
- **Многогранник** (Werner & Scheeres 1997): точное поле однородного замкнутого многогранника
  внутри и снаружи; лапласиан по телесным углам; на поверхности (рёбра, вершины, диагонали
  граней) потенциал и ускорение берут свои пределы — ошибки нет. Проверка — замкнутая формула
  прямоугольной призмы (Nagy et al. 2000) в 40 знаках: 3·10⁻¹⁶ / 7,6·10⁻¹⁶ × max(1, (r/размер)²)
  (члены растут как r², поле падает как 1/r — это записано в контракте). Сетка проверяется на
  замкнутость и ориентацию.
- **Масконы**: сумма точечных масс с компенсацией в порядке массива; против своего ряда
  гармоник до степени 40 (независимая рекурсия Лежандра) — 1,2·10⁻¹⁵.
- **Фигура–фигура**: член l = l′ = 2 взаимного потенциала в STF-форме (Damour, Soffel, Xu
  1991): U₂₂ = G/(36 r⁵)[105 (n·Q_A·n)(n·Q_B·n) − 60 n·Q_A Q_B·n + 6 tr(Q_A Q_B)], силы на оба
  центра масс; члены «поле одного в центре другого» — гармониками любой степени. Проверка:
  два облака точечных масс без нечётных моментов, точная двойная сумма: U₂₂ уменьшает ошибку
  взаимной силы в 29 раз на 12 размерах и в 95 раз на 24, остаток падает как r⁻⁸.
  Q из нормированных C₂ₘ, S₂ₘ и его поворот проверены против степени 2 поля.
- **Эллипсоидальные гармоники** (Garmier & Barriot 2001): функции Ламе четырёх классов K, L,
  M, N из трёхчленных рекуррентностей (выведены подстановкой в уравнение Ламе; собственные
  значения вещественны и различны — корни континуанты, затем корни многочлена Q в (0, k²) по
  Стилтьесу). Внешний член F(λ)E(μ)E(ν) = R(λ)·H(x, y, z), где H — декартов гармонический
  многочлен Нивена (произведение квадрик (t−h²)(t−k²)(x²−t) + y²t(t−k²) + z²t(t−h²)), а
  R(λ) — интеграл в форме с ограниченным подынтегральным выражением: градиент без особых
  множеств эллипсоидальных координат. Проверка: гармоничность каждого базисного члена до
  степени 16; форма Нивена против E(μ)E(ν) в координатах из кубики — 3·10⁻¹²; брусок 4×2,4×1,6
  (точное поле — многогранник) внутри сферы Бриллюэна: эллипсоидальный ряд 8,9·10⁻³ → 6,5·10⁻⁵
  от степени 4 до 16, сферический ряд того же бруска (точные моменты) расходится
  3,8·10⁻² → 0,26.
- **Приливы** (IERS 2010 гл. 6, все числа — данные `data/grav/iers2010-tides.tk`): шаг 1 с
  комплексными числами Лява и k⁽⁺⁾ для степени 4; шаг 2 — 71 строка табл. 6.5a–c как ряды
  Пуассона по χ = GMST + π и аргументам Делоне (скрипт преобразования сверил в каждой строке
  число Дудсона с множителями и множители Дудсона с множителями Делоне); шаг 3 — постоянный
  прилив для zero-tide полей (выбор по `tide_system` файла, без угадывания для mean-tide);

  теоремы сложения (k GMⱼR²ⁿ⁺¹/(rⁿ⁺¹rⱼⁿ⁺¹) Pₙ(cos ψ)) — 2·10⁻¹⁶; шаг 2 против примера K1 из

### Решения фазы 6

- **EIH в задаче N тел** (`MYB_INTERACTION_EIH`, `myb_nbody_set_relativity`, `myb/dyn.h`):
  уравнения Эйнштейна–Инфельда–Хоффмана с параметрами PPN β, γ в форме Мойера (DESCANSO 2,
  ур. 4-61) — те же, что интегрируют эфемериды JPL. Граф взаимодействий хранит исключения
  (NONE) и явные уровни NEWTON/EIH; по умолчанию после `set_relativity` все пары — EIH.
  Потенциалы U_i и ньютоновские ускорения a_j в членах 1PN берутся по графу. Ньютоновский
  проход не изменился (симметричный, векторный, параллельный — те же биты: старый эталон
  воспроизводимости без новых нагрузок не сдвинулся ни на бит); за ним — проход потенциалов и
  проход членов 1PN по приёмникам в порядке возрастания источника со своим Sum2. Ускорения
  зависят от скоростей: `myb_nbody_acceleration` без скоростей и интеграторы Уиздома–Холмана
  такую систему отвергают (`MYB_E_DOMAIN`).
- **Независимая проверка EIH**: уравнения Эйлера–Лагранжа глобального лагранжиана PPN
  (Bernus et al. 2023, arXiv:2301.01186, прил. B), выведенные символьно (sympy) и решённые до
  первого порядка по 1/c² в арифметике 50 знаков (mpmath): 48 случаев, 2–5 тел, (β, γ) =
  (1, 1), (1,3, 0,7), (0,8, 1,25), c = 10 и 1000 — ошибка 2,7·10⁻¹⁰ от величины членов 1PN
  (они ≥ 1,6·10⁻⁶ ньютоновских: т. е. округление double), все пути и пулы — одни и те же биты.
- **Интегралы 1PN** (`myb_nbody_pn_invariants_of`): энергия, импульс и релятивистский
  барицентр (начало BCRS эфемерид JPL) по тому же лагранжиану. Тройная система, v/c ~ 10⁻²,
  60 единиц времени (IAS15): энергия 1PN меняется на 6·10⁻⁹ при изменении ньютоновской 1,6·10⁻⁵;
  при удвоении c — в 12 раз меньше (ожидаемый порядок c⁻⁴ плюс шум интегрирования).
- **Перигелий Меркурия** (Солнце и Меркурий, GM DE440, 60 оборотов, перигелии найдены событием
  r·v = 0): 42,9804″ за столетие против 6πGM/(c²a(1−e²)) — расхождение 5·10⁻⁹; при
  (β, γ) = (1,5, 0,7) и (0,6, 1,3) множитель (2 + 2γ − β)/3 воспроизведён до 1,3·10⁻⁷ (поправки
  конечной массы Меркурия, отношение масс 1,7·10⁻⁷).
- **Спутник в локальной системе** (`myb/rel.h`, IERS 2010 ур. 10.12): члены Шварцшильда,
  Лензе–Тирринга (спин центрального тела) и де Ситтера (внешнее тело) — отдельными функциями.
  Орбита LAGEOS, 600 оборотов IAS15: прецессия узла от Лензе–Тирринга 30,631 mas/год и от
  де Ситтера 19,188 mas/год — совпадают с аналитическими 2GMj/(c²a³(1−e²)^{3/2}) и
  (3/2)GM☉n/(c²a☉) до округления; перигей эксцентричной орбиты (e = 0,3) за 200 оборотов — с
  формулой и множителем (2 + 2γ − β)/3.
- **Локальная система** (`myb_rel_global_to_local`, Resolution B1.3 МАС 2000, Soffel et al.
  2003): X = r + c⁻²[½v_E(v_E·r) + w_ext r + r(a_E·r) − ½a_E r²] и обратное до O(c⁻⁴);
  в пределе без поля и ускорения совпадает с преобразованием Лоренца (до 10⁻⁹ м на 6800 км);
  поправка на орбите 6800 км — 66 мм. Сдвиг времени −v_E·r/c²; TCB − TCG в центре — модуль time.
  **Собственное время** (ур. 10.6–10.9): часы GPS идут быстрее TT на 4,4647·10⁻¹⁰ — ровно
  величина, которую компенсирует сдвиг частоты GPS (IERS 2010, §10.2).
- **DE440** (`test_de440_rel`, нужна `data/download`): Солнце, планеты (барицентры систем), Земля

UBSan ловят подложенные утечку, выход за массив и переполнение.

**ThreadSanitizer** (`linux-tsan`, `-O2 -fsanitize=thread`, 153 единицы компиляции,
`TSAN_OPTIONS=halt_on_error=1:abort_on_error=1:second_deadlock_stack=1:report_signal_unsafe=1:history_size=7`),
2026-11-09, та же ВМ (8 логических процессоров): все 39 тестов — 39/39 без единого отчёта
(57 с); затем многопоточные тесты — `test_pool` (пулы 1–13 потоков, произвольные разбиения
диапазонов), `test_nbody` (ускорения на 1–13 потоках, все пути, векторные блоки, интегрирование
с пулом), `test_whfast` (WH с пулом и без), `test_repro` (N тел на 1 и 4 потоках) — повторены
по 30 раз (`ctest --repeat until-fail:30`, 120 прогонов, 208 с): ни одной гонки данных, ни
одной инверсии порядка блокировок. Положительный контроль (два потока без синхронизации
увеличивают общий счётчик) TSan ловит («data race», код 66). Что это подтверждает: общее
состояние команды потоков (`generation`, `pending`, `busy`, `job`) меняется только под
мьютексом, рабочие потоки пишут непересекающиеся части результата, а всё, что они записали,
видно вызывающему потоку после `myb_platform_team_run` (отношение happens-before через
мьютекс и условную переменную). Не проверено: реализация на Win32 (SRWLOCK) — TSan для
mingw-w64 не существует; она устроена так же и даёт те же биты (`test_repro`).

Найдено и исправлено (на Windows не проявлялось):
- `platform_posix.c` впервые скомпилирован: в строгом C23 glibc не объявляет `O_CLOEXEC` —
  добавлен `_POSIX_C_SOURCE 200809L`;
- `fegetround`/`feraiseexcept` (CORE-MATH) в glibc живут в libm — `myb` линкуется с `m` на
  не-Windows (запрет неточных функций libm проверяет `test_no_libm_imports`);
- `-Wpsabi`: в ABI SysV 32-байтовые векторы Clang, переданные по значению без AVX, меняют
  соглашение о вызове — векторные блоки `dyn/nbody.c` теперь передаются по указателю (биты не
  изменились);
- проверка пар указателей ASan при `-O2` (Clang 21) срабатывает на сравнениях, которые создаёт
  оптимизатор (указатель против −9): при `-O0` те же 39 тестов чисты, поэтому `pointer-compare`
  и `pointer-subtract` включены только в Debug-сборке ASan.

### Решения фазы 4

- **Система N тел** (`myb_nbody`, `myb/dyn.h`): тела заданы только GM; массивные (притягивают)
  и пробные (чувствуют массивные, сами не притягивают). Ускорение приёмника — прямая сумма по
  всем источникам в порядке возрастания j со сложением Sum2 (TwoSum на каждый член, ошибки —
  отдельно; Ogita, Rump, Oishi 2005). Проверено против суммы в double-double: ошибка
  ≤ 3,5·10⁻¹⁶ от Σ|членов| (простое суммирование тех же членов — 2,1·10⁻¹⁵), 400 + 50 тел с GM
  от 10⁵ до 10²⁰.
- **Независимость от потоков и путей.** Симметричный путь (каждая пара один раз, член для j —
  −(GM_i q dx), побитово равный GM_i q (x_i − x_j)) и путь «по приёмникам» дают одни и те же
  биты: порядок членов у каждого приёмника одинаков. Путь по приёмникам параллелится по i через
  `myb_pool` (платформенный слой: Win32 SRWLOCK/CONDITION_VARIABLE, POSIX pthread; потоки
  создаются один раз и ждут работы) и считает приёмники блоками по 4 в векторах Clang (без
  интринсиков: пары SSE на x86-64-v2, AVX на v3, NEON на ARM) — каждая полоса делает ровно
  скалярные операции; собственная пара гасится маской, а прибавление точного +0 к Sum2 не
  меняет ни бита (ни s, ни c не бывают −0). Тест сравнивает все пути, все хвосты (1–17
  массивных + 0–6 пробных), пулы 1–13 потоков и произвольные границы частей — бит в бит.
  Замер (2000 тел, один поток, на взаимодействующую пару): симметричный 15,8 нс, векторный по
  приёмникам 12,2 нс на v2 и 6,2 нс на v3 (хотя каждая пара считается дважды), скалярный по
  приёмникам 17 нс; 733 тела на 8 потоках — 0,60–0,90 мс против 3,8–4 мс симметричного.
- **Граф взаимодействий**: уровень на каждую направленную пару (сейчас `NONE` и `NEWTON`; уровни
  гармоник, 1PN, приливов добавят следующие фазы); исключения хранятся отсортированными, приёмник
  суммирует промежутки между исключёнными источниками без ветвлений во внутреннем цикле. Найдено
  при проверке: граница цикла по промежуткам вычислялась от изменяющегося счётчика и обрезала
  хвост источников у приёмника с многими исключениями — исправлено, добавлена проверка
  «все источники пройдены, все исключения учтены» (`MYB_CHECK`).
- **Инварианты** (энергия, импульс, момент, центр масс) — в double-double; энергия как G·E
  (тела заданы GM): разрешаются ошибки интегрирования 10⁻¹⁶.
- **Классические решения** (тест `test_nbody`): решение Лагранжа (GM 1, 10⁻³, 10⁻⁶, устойчиво
  по Раусу) — 20 периодов IAS15, отклонение от жёсткого вращения 1·10⁻¹³ стороны; «восьмёрка» —
  начальное условие уточнено стрельбой Гаусса–Ньютона от 6-значных значений Šuvakov &
  Dmitrašinović 2013: p₁ = 0,3471168881189257, p₂ = 0,5327249453880308,
  T = 6,3259139829262061, невязка за период 1,9·10⁻¹⁵; совпадает с условием Симо (8 знаков) до
  10⁻⁹ и 3·10⁻⁸ по периоду; 10 периодов — возврат к началу 2·10⁻¹⁴, энергия 3·10⁻¹⁶;
  пифагорова задача Бурау — тесное сближение 4,1·10⁻⁴ при t = 15,83, к t = 70 тела с GM 4 и 5
  образуют двойную, тело с GM 3 уходит (как у Szebehely & Peters 1967); IAS15 и RKN12(10)
  совпадают до 4·10⁻¹² при t = 10, а к t = 70 хаос усиливает округление до 2·10⁻² при одном и
  том же исходе; энергия сохраняется до 10⁻¹⁰.
- **IAS15 исправлен по статье**: «восьмёрка» нашла, что минимум τ по блокам останавливает шаг,
  когда ускорение одного тела проходит через нуль (среднее тело симметричной коллинеарной
  конфигурации, `MYB_E_NOCONV` на первом шаге). В статье (Pham, Rein & Spiegel 2024, ур. 7)
  нормы берутся по всему 3N-вектору: максимум по телам евклидовых норм, отдельно для a, a′, a″ —
  так и сделано; тесты фазы 3 прошли без изменения порогов.
- **Дрейф Кеплера в форме приращения** (`kepler/drift.h`): Δr = (f − 1) r₀ + g v₀,
  Δv = ḟ r₀ + (ġ − 1) v₀ с f − 1 = −U₂/r₀, ġ − 1 = −U₂/r без вычитания из единицы;
  `myb_kepler_propagate` теперь возвращает r₀ + Δ (одно округление вместо трёх; ошибка против
  MPFR ≤ 4,7·10⁻¹⁵, на 1–30 витках ≤ 2·10⁻¹⁵), матрица перехода — то же состояние бит в бит.
- **WH/WHFast** (`myb_wh`): разбиение Уиздома–Холмана в канонических координатах Якоби
  (кеплеровская часть с GM = η_i, дрейф — универсальный пропагатор для всех конических сечений;
  удар — полное ускорение N тел, переведённое в Якоби, плюс кеплеровский член; центр масс
  дрейфует свободно, его ускорение — точно 0 при взаимном графе). Состояние Якоби накапливается
  с компенсацией. Схемы: DKD (= SABA1), SABA2–4 (узлы и веса Гаусса–Лежандра), SBAB1–4 (Гаусса–
  Лобатто; ускорение последнего удара переиспользуется первым ударом следующего шага).
  Коэффициенты — из замкнутых форм, проверены в MPFR бит в бит; квадратуры точны ровно до
  степени 2n − 1 (`test_mpfr_wh`).
- **Симплектические корректоры** (порядки 3, 5, …, 17) выведены здесь: в первом порядке по
  возмущению DKD = exp(hA + φ(h ad_A) hB), φ(t) = (t/2)/sinh(t/2); корректор C = exp(χ),
  χ = −h ((1 − φ(t))/t) B — нечётный ряд с числами Бернулли; C собирается из
  Z(a, b) = A(a)B(b)A(−2a)B(−b)A(a) как Z(a_m, b_m)…Z(a_1, b_1)Z(−a_1, −b_1)…Z(−a_m, −b_m)
  (C⁻¹ — тот же с −b), a_i = i·√(7/40) (выбор Wisdom et al.), b — решение линейной системы
  в MPFR. Для порядка 3 b₁ = 1/(96·√(7/40)) = 0,0249005960277998675 — опубликованное значение,
  т. е. вывод воспроизводит Wisdom, Holman & Touma 1996. Корректор применяется только к
  выдаваемым состояниям; ядро шагает некорректированным.
- **Проверка WH** (`test_whfast`): два тела — поток Кеплера, 2000 шагов — 1·10⁻¹¹ a (шум
  округления дрейфов: каждый точен до долей ulp по скорости, энергия блуждает как у IAS15);
  наблюдаемые порядки при малом возмущении (ε = 10⁻⁷): DKD 2,00, корректоры 3/5 — 4,00/5,81,
  SABA2/SBAB2 — 3,93/3,96, схемы 6–8 порядков достигают округления уже на 16 шагах за виток;
  Юпитер–Сатурн, 100 витков Сатурна, 50 шагов за виток Юпитера против IAS15: DKD 9·10⁻⁵,
  корректор 17 — 1·10⁻⁵ (по положению остаётся член ε²h², который корректор не трогает; энергия
  1,9·10⁻⁷ → 1,9·10⁻¹⁰), SABA4/SBAB4 — 9·10⁻⁷; 5000 витков с корректором 17 — энергия
  ограничена (≤ 7·10⁻¹⁰); 3000 шагов вперёд и назад — 1,3·10⁻¹³; плотный вывод внутри шага —
  с той же точностью, что и узлы; пробное тело; одинаковые биты с пулом потоков и без.
- **Воспроизводимость**: в эталон добавлены ускорения N тел (с исключением, 1 и 4 потока —
  сравниваются побитово), инварианты, «восьмёрка» IAS15, схемы WH с корректором и плотным
  выводом; новый эталон 0xde3d79ea60027aae одинаков при -O0/-O2/-O3, x86-64-v2/v3 и под UBSan.

### Решения фазы 3

- **DOP853** — коэффициенты взяты текстом из SciPy (BSD-3), структура оценки ошибки и плотного
  вывода — по Хайреру; состояние и время обновляются с компенсацией (TwoSum), память выделяется
  один раз при создании. Плотный вывод 7-го порядка строится лениво (3 доп. вычисления правой
  части). Шаг, укороченный до границы `t_limit`, не уменьшает следующий: сохраняется
  запланированный (у Хайрера следующий шаг считался от укороченного). Проверено: условия порядка
  (все деревья до 5-го порядка, квадратуры до 8-го), наблюдаемый порядок 7,4 → 7,8 (сходится к 8),
  10 витков e = 0,7 при rtol 10⁻¹³ — 1,3·10⁻¹⁰, плотный вывод 2,4·10⁻¹², события 7,7·10⁻¹⁰ с,
  матрица перехода из вариационных уравнений против центральных разностей — 3·10⁻⁹ (предел
  разностей). На 10⁴ витках ошибка 2·10⁻⁵: метод не симплектический, дрейф энергии линейный —
  для длинных дуг нужен IAS15.
- **IAS15** реализован по статьям (Rein & Spiegel 2015; Everhart 1985), а не по коду REBOUND
  (GPL). Узлы Гаусса–Радау и таблицы C, D, R вычислены в MPFR (512 бит); тест
  `test_mpfr_radau` пересчитывает каждый элемент и сравнивает бит в бит. Критерий шага —
  PRS23 (Pham, Rein & Spiegel 2024, ур. 15–17): τ² = 2|a|²/(|a′|² + |a||a″|),
  dt = (7!ε)^{1/7}·τ; нормы a, a′, a″ — максимум по блокам компонент (тело = 3 компоненты)
  евклидовой нормы блока, как в ур. 7 статьи (до фазы 4 здесь был минимум τ по блокам — см.
  «Решения фазы 4»). Предсказание b для следующего шага — переразложение многочлена шага
  плюс поправка прошлого шага, масштабированная q^{k+1}. Итерации останавливаются на 10⁻¹⁶ или
  когда поправка перестала убывать (≤ 12 проходов); непрошедшие считаются в статистике.
  Проверено: локальный порядок 15,6; 10 витков при e = 0…0,99 — от 2·10⁻¹⁵ до 1,6·10⁻¹³
  периода; 10⁴ витков e = 0,3 — 2,8·10⁻¹¹ периода (DOP853 на той же дуге — 2·10⁻⁵); гипербола;
  закон Брауэра (ансамбль, e = 0,5): наклон 0,44, 4,6·10⁻¹⁵ за 1000 витков;
  сила, зависящая от скорости (заряд в полях) — 3·10⁻¹⁶.
- **Ограничения IAS15**, найденные при проверке: (1) τ из PRS23 относительна к норме a и
  стремится к нулю там, где ускорение всего состояния обращается в нуль, — одномерный осциллятор
  заканчивается `MYB_E_STEP_MIN` (для таких задач — DOP853); система тел этого не встречает. (2) На точно круговой орбите с постоянным шагом ошибки округления соседних шагов
  одинаковы и не усредняются: энергия дрейфует ~10⁻¹⁷ за виток (3·10⁻¹⁴ за 3000 витков; от ε
  не зависит — это округление, а не усечение). В несимметричных системах действует закон Брауэра.
- **Поиск событий** — общий для интеграторов: Иллинойс по плотному выводу до соседних double.
- **Симплектические композиции** (`myb_symplectic`): leapfrog «толчок–дрейф–толчок» и тройной
  прыжок Йошиды (порядки 2, 4, 6, 8; 1, 3, 9, 27 вычислений на шаг). Время — координата
  расширенного фазового пространства, поэтому отображение симплектично и для потенциала,
  зависящего от времени; силы, зависящие от скорости, сюда не входят (для них — IAS15). Веса
  вычислены в MPFR и проверяются бит в бит (`test_mpfr_yoshida`). Проверено: наблюдаемые
  порядки 2,00 / 4,00 / 6,05 / 7,98; ошибка энергии ограничена — одинакова на 1–100 и на
  4901–5000 витках (у DOP853 на тех же длинах она растёт линейно); 10 витков вперёд и назад
  — 1,7·10⁻¹². Решения Йошиды с меньшими константами ошибки (7 и 15 стадий) требуют решения
  уравнений порядка с нуля — оставлены на потом. Разложено по фазам или закрыто — см. «Старые долги (фазы 3–11) и привязки».
- **Гаусс–Джексон 8-го порядка** (`myb_gauss_jackson`) в суммированной ординатной форме.
  Коэффициенты выведены заново из операторных тождеств hv − s = P₁(D)h²a,
  x − S = P₂(D)h²a с P₁ = 1/D − 1/(eᴰ − 1), P₂ = 1/D² − eᴰ/(eᴰ − 1)² (числа Бернулли) на
  интерполянте 8-й степени окна u = −4…4 — точными рациональными числами; строка предиктора
  совпала с опубликованной (Berry & Healy 2004: 3250433/53222400, …, 103798439/159667200), тест
  `test_mpfr_gauss_jackson` пересчитывает все 261 число бит в бит. Суммы — с компенсацией.
  Старт — итерация самих формул по узлам −4…4 из тейлоровского приближения (сила должна быть
  определена и на 4 шага назад). Плотный вывод — точный интеграл интерполянта окна, события —
  общим поиском. Контроля шага нет; статистика отдаёт разность предиктор–корректор как оценку
  локальной ошибки. Найдено при проверке: «застой» итерации нельзя считать сходимостью, если
  поправка велика (при слишком длинном шаге старт иначе «сходился» к мусору) — теперь застой
  принимается только ниже 10⁻¹⁰. Проверено: наблюдаемый порядок по положениям ~10 (окно
  точно для ускорения 8-й степени — положения точны до 10-й), 100 витков при 200 шагах на
  виток — 8,9·10⁻¹³ периода при 2,55 вычисления на шаг, сила Лоренца — 6·10⁻¹⁷, обратный ход.
- **RKN12(10)** (Dormand, El-Mikkawy & Prince 1987) для x″ = a(t, x): коэффициенты — точные дроби
  `DPRKN12Tableau` из OrdinaryDiffEq.jl (MIT); тест `test_mpfr_rkn12` в рациональной арифметике
  GMP проверяет, что каждый double — ближайший к своей дроби, и заново выполняет условия порядка:
  квадратуры 12-го порядка, b = b′(1 − c), моменты вложенного решения 10-го порядка, суммы строк
  c²/2 (строки 14–17 в источнике — 50-значные значения, совпадают до 10⁻⁵³). Контроль шага —
  0,9·err^(−1/11) по положениям и скоростям. Своего интерполянта у пары нет, поэтому плотный
  вывод — ещё один шаг пары от начала последнего шага (16 вычислений), точный как сами шаги.
  Проверено: наблюдаемый порядок 12,4; 10 витков e = 0,9 при rtol 10⁻¹⁴ — 4,8·10⁻¹⁵ периода за
  758 шагов; события 1,5·10⁻¹⁰ с.
- **Счётчики статистики и бюджеты шагов** — `int64_t`: `long` на Windows 32-битный и
  переполнился бы на длинных прогонах (10⁹ витков).
- **Матрица перехода двух тел** (`myb_kepler_stm`) — в замкнутой форме: коэффициенты Лагранжа,
  продифференцированные через универсальное уравнение Кеплера (производные U_n по α при
  фиксированном χ: −(χU_{n+1} − nU_{n+2})/2, нужны c₄, c₅ — ряды при |z| < 4). Те же пути,
  что у пропагатора: снятые целые периоды дают явный вековой член (зависимость периода от
  энергии), гипербола вдали от перицентра — композиция двух дуг от перицентра, обратная
  симплектической матрице берётся точно (транспонированием блоков). Эталон — центральные
  разности 400-битной пропагации в MPFR: ≤ 3·10⁻¹⁵ (в масштабах r₀, v₀), в том числе на
  1–30 витках; симплектичность 3·10⁻¹⁴; DOP853 с вариационными уравнениями (rtol 10⁻¹³)
  совпадает с ней до 2·10⁻¹³.
- **Найдено при проверке матрицы и исправлено в пропагаторе фазы 2**: α = 2/r₀ − v²/μ и период
  считались в double; сокращение членов (до 2a/r₀ ≈ 39 при e = 0,95) оставляло в периоде
  несколько ulp, и каждый снятый период добавлял фазовую ошибку — 2,8·10⁻¹¹ после 30 витков.
  Теперь |r₀|², |v₀|², α и период — в double-double: 1–30 витков ≤ 1,9·10⁻¹⁵, один виток
  ≤ 4,6·10⁻¹⁵ для всех конических сечений (было ≤ 1,1·10⁻¹⁴). Тест MPFR дополнен
  многовитковыми случаями, пороги ужесточены до 10⁻¹⁴.
- **Воспроизводимость**: в эталонную нагрузку добавлены DOP853 (J2) и IAS15 (три тела) с
  плотным выводом и событиями, матрица перехода двух тел, композиции порядков 2–8,
  Гаусс–Джексон, RKN12(10); новый эталон 0x49a0d3f351af2744 одинаков при -O0/-O2/-O3,
  x86-64-v2/v3 и под UBSan.

- **Один гарантированный решатель** (`num/root.c`): Ньютон в вилке с правилом rtsafe. Первая
  версия возвращала середину вилки, когда шаг Ньютона был меньше ulp (`next == lo`); найдено
  сверкой с путём через элементы, исправлено, покрыто тестами.
- **Пропагатор**: универсальные переменные; эллипсы — снятие целых периодов в double-double;
  гиперболы далеко от перицентра (|H₀| > 1) — пересчёт от перицентра (иначе члены уравнения
  ~10⁴ раз больше результата). Почти параболические — прямой путь (там α плохо обусловлена,
  а прямому пути она почти не нужна). Сверка с MPFR 400 бит: ≤ 2·10⁻¹⁴.
- **Ламберт** (Izzo 2015) с гарантированным решателем вместо Хаусхолдера; вторым методом
  (Gooding) служит независимая проверка: каждое решение прогоняется пропагатором до r₂.
- **Не сделано в фазе 2**: аналитическая матрица перехода состояния двух тел (Shepperd 1985) —
  перенесена в фазу 3 вместе с вариационными уравнениями интеграторов (сделана в фазе 3).
- **Обусловленность элементов**: классические и равноденственные элементы почти параболических
  орбит вдали от перицентра плохо обусловлены (сдвиг ν на ulp меняет r в (1 − e)⁻¹ раз);
  это свойство параметризации, в тестах эта область исключена и описана.

### Решения фазы 1

- **Формат данных — текстовые ядра NAIF.** Документированный формат, в котором JPL уже
  распространяет свои ядра; один загрузчик для наших конвенций и для `gm_de440.tpc` и т.п.
- **Шкалы времени — значения во время выполнения, а не типы C.** План предполагал отдельный тип
  на шкалу, но шкалы задаются данными (ядро не знает слова «TT»), поэтому мгновение — это
  `myb_time`, а шкала — дескриптор `myb_scale` системы `myb_timesys`; смешение шкал ловится
  явным преобразованием по дереву, а не компилятором.
- **UTC — только календарные метки.** UTC не непрерывная шкала; в дереве её нет, а
  преобразования идут через таблицу с датой истечения (после неё — `MYB_E_RANGE`).
- **TDB−TT — ряд Fairhead & Bretagnon** (несколько нс); точное соотношение TCB−TCG по
  эфемериде появится с модулем `rel` (фаза 6). Топоцентрические члены относятся к собственному
  времени наблюдателя и в конвенцию шкалы не входят.
- **Свой разбор чисел**: быстрый путь Клингера + проверка большими целыми относительно середин;
  `strtod` не используется (зависит от локали и CRT).
- **Вывод чисел (Ryu)** отложен до фазы, где появится запись результатов (CCSDS OEM).
