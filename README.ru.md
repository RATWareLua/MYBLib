# MYBLib

[English](README.md) | **Русский**

Библиотека для моделирования и расчёта движения объектов в космосе.

`myb` — библиотека на C23 для расчёта движения объектов в космосе: N тел, околопланетные орбиты,
межпланетные перелёты, свободное движение. Модели — на реальных законах физики (включая ОТО в
пост-ньютоновском приближении там, где эффект измерим), результат воспроизводим до бита на
Windows и Linux. Ядро не знает ни одного конкретного тела: Солнце, планеты и аппараты
задаются данными.

Состояние: **версия 1.2.0.0, фазы 0–17** — числовой фундамент, корректно округлённые функции, чтение данных,
шкалы времени, модель тела, задача двух тел, задача Ламберта, интеграторы (DOP853,
RKN12(10), IAS15, Гаусс–Джексон, симплектические композиции), задача N тел (прямое
суммирование, граф взаимодействий, потоки, WH/WHFast, SABA, SBAB), эфемериды SPK и системы
отсчёта (IAU 2006/2000A, EOP, WGCCRE, PCK, геодезия, орбитальные системы), ОТО в
пост-ньютоновском приближении (EIH с PPN, Лензе–Тирринг, де Ситтер, локальные системы), поля
тяготения протяжённых тел (сферические и эллипсоидальные гармоники, многогранники, масконы,
фигура–фигура), приливы, негравитационные силы, атмосфера NRLMSISE-00, модель сил объекта,
вариационные уравнения и ковариации, ограниченная задача трёх тел, B-плоскость и наведение,
бюджет эффектов, ориентация и вращательная динамика (точный свободный волчок, жидкое ядро,
либрации Луны), регуляризация Кустаанхеймо–Штифеля и Сундмана, малая тяга, равноденственные
системы и TEME, SGP4 и SPK тип 10, компактные двойные до 3,5PN со спинами, наблюдаемые (световое время,
задержка Шапиро, двусторонние измерения, аберрация, отклонение света, задержка в плазме,
тропосфере и ионосфере), магнитные поля, сила Лоренца, плазма и зарядка тел, окружение модели
сил с готовыми членами, распространение объекта, оценивание орбит (со сдвигами измерений и
сглаживателем), вывод (точная печать чисел, SPK и бинарный PCK, сообщения CCSDS в нотациях
KVN и XML, SP3, TLE), события на орбите, геометрия поверхностей и малые
силы: торможение Пойнтинга–Робертсона, кометы и эффект Ярковского, запаздывающий прилив,
тепловая отдача, пластины и сетки с ориентацией, самозатенением и свободномолекулярным
обтеканием, импульсы. Подробный план, источники и дорожная карта —
[`docs/PLAN.ru.md`](docs/PLAN.ru.md); происхождение данных — [`data/README.ru.md`](data/README.ru.md).

## Сборка

Нужны Clang ≥ 19 и CMake ≥ 3.28. Сборка только Clang'ом.

**Windows.** Clang (LLVM для Windows) и MSYS2 с окружением MINGW64 (`C:\msys64\mingw64`:
заголовки, runtime, `mingw32-make`; для тестов точности — пакеты `mpfr`, `gmp`). Visual Studio не нужна.
Другой путь к MSYS2 — переменная окружения `MYB_MINGW_ROOT`.

```
cmake --preset windows-dev
cmake --build --preset windows-dev --parallel
ctest --preset windows-dev
```

**Linux (Gentoo и др.).** `clang`, `ninja`, для тестов точности — `mpfr`.

```
cmake --preset linux-dev
cmake --build --preset linux-dev --parallel
ctest --preset linux-dev
```

Пресеты: `*-dev` (Debug, `-Werror`), `*-release` (`-O2`, проверки контрактов сохраняются),
`windows-ubsan` (UBSan в режиме trap); на Linux — санитайзеры с остановкой на первой ошибке:
`linux-asan` (ASan + UBSan + LeakSanitizer, `-O2`), `linux-asan-debug` (то же при `-O0` и
проверка пар указателей `pointer-compare`/`pointer-subtract`), `linux-ubsan` (UBSan с отчётом и
стеком), `linux-lsan` (отдельный LeakSanitizer), `linux-tsan` (ThreadSanitizer: гонки данных и
порядок блокировок пула потоков). Результаты проверки на Gentoo — `docs/PLAN.ru.md`, §12.

Тест `test_repro` сравнивает хеш результатов с эталоном: он обязан совпасть на любой
платформе, при любом уровне оптимизации и ISA (x86-64-v2/v3).

**CI** (`.github/workflows/ci.yml`, GitHub Actions): те же пресеты — Linux (Ubuntu 24.04,
Clang 20): `linux-dev`, `linux-release`, `linux-asan`, `linux-asan-debug`, `linux-ubsan`,
`linux-lsan`, `linux-tsan`; Windows (Clang + MSYS2 MINGW64): `windows-dev`, `windows-release`,
`windows-ubsan`. Данные скачиваются `FetchData.cmake` и кешируются, живые ряды EOP при каждом
прогоне обновляются. Запуск — только при отправке тега (выпуск) и вручную (`workflow_dispatch`),
не на каждый push.

## Установка и использование

```
cmake --build --preset linux-release --parallel
cmake --install build/linux-release --prefix /opt/myb
```

Ставятся заголовки, `libmyb.a`, библиотеки `ext/`, ядра данных (`share/myb/data`) и пакет
CMake. Пресеты `*-release` собирают ещё и разделяемую библиотеку (`MYB_BUILD_SHARED`:
`libmyb.so` / `libmyb.dll`), из которой экспортируется только публичный API. Сторонний проект —
любым компилятором C17 или C++17:

```cmake
find_package(myb 1.2 REQUIRED)
target_link_libraries(app PRIVATE myb::myb)        # или myb::myb_shared; myb::sgp4, ...
target_compile_definitions(app PRIVATE "DATA_DIR=\"${myb_DATA_DIR}\"")
```

Без CMake — `pkg-config --cflags --libs myb` (библиотеки `ext/` — `myb_sgp4`, `myb_nrlmsise00`,
`myb_troposphere`, `myb_ionosphere`). Разделяемая библиотека на ELF несёт версии символов
(`MYB_1.0`, `MYB_1.1`, `MYB_1.2`). Примеры — [`examples/`](examples): низкая орбита
у сплюснутой планеты с атмосферой (готовые члены модели сил, события, прецессия узла) и шкалы
времени из ядер данных; собираются в дереве (`-DMYB_BUILD_EXAMPLES=ON`) или отдельно против
установки (`cmake -S examples -B build-examples -DCMAKE_PREFIX_PATH=/opt/myb`). История
изменений — [`CHANGELOG.ru.md`](CHANGELOG.ru.md).

## Числовой контракт

IEEE-754 binary64, округление к ближайшему; библиотека не меняет окружение плавающей точки.
Сборка принудительно выключает слияние `a*b+c` в FMA и fast-math, а `-ffast-math` от
пользователя останавливает компиляцию. Подробно — `docs/PLAN.ru.md`, §7.
