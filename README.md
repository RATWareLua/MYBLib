# MYBLib
Bibliothek zur Simulation und Berechnung von Objektbewegungen im Weltraum

`myb` — библиотека на C23 для расчёта движения объектов в космосе: N тел, околопланетные орбиты,
межпланетные перелёты, свободное движение. Модели — на реальных законах физики (включая ОТО в
пост-ньютоновском приближении там, где эффект измерим), результат воспроизводим до бита на
Windows и Linux. Ядро не знает ни одного конкретного тела: Солнце, планеты и аппараты
задаются данными.

Состояние: **фазы 0 и 1** — числовой фундамент, корректно округлённые функции, чтение данных,
шкалы времени, модель тела. Подробный план, источники и дорожная карта —
[`docs/PLAN.md`](docs/PLAN.md); происхождение данных — [`data/README.md`](data/README.md).

## Что уже есть

| Модуль | Содержание | Проверено |
|---|---|---|
| `myb/core.h` | коды ошибок, версия, распределитель памяти, диагностика | |
| `myb/num.h` | TwoSum, TwoProd, double-double (+ − × ÷ √), Sum2, Dot2 | точность против MPFR: все операции в пределах доказанных границ |
| `myb/cmath.h` | `myb_fma`, `myb_sin`, `myb_cos` — корректно округлённые | `fma`: 12·10⁶ входов бит в бит с аппаратной FMA; `sin`/`cos`: 1,27·10⁶ входов (включая трудные случаи CORE-MATH) бит в бит с MPFR |
| `myb/io.h` | разбор чисел с корректным округлением (не зависит от локали и CRT); текстовые ядра NAIF | 4,2·10⁵ строк бит в бит с MPFR, включая точные середины между double и строки длиннее 800 цифр |
| `myb/time.h` | мгновения (целые секунды + доля, разрешение < 10⁻¹⁶ с), календарь, юлианские даты; шкалы TAI, TT, TCG, TDB, TCB, GPS, GST, BDT и UTC из данных | против IAU SOFA (ERFA): календарь — 0, TDB−TT — 8·10⁻¹⁶ с, TT↔TCG и TDB↔TCB — 1,3·10⁻¹¹ с, UTC→TAI — 3,2·10⁻¹¹ с (предел — разрешение двухчастной JD у SOFA) |
| `myb/body.h` | параметры с погрешностью, GM из массы, тело (GM, вид движения) | |

Данные (`data/`): дерево шкал времени по резолюциям МАС, ряд TDB−TT Fairhead & Bretagnon,
таблица TAI−UTC с 1960 г. (до 28.06.2027 по бюллетеню IERS C 72), CODATA 2022.

## Сборка

Нужны Clang ≥ 19 и CMake ≥ 3.28. Сборка только Clang'ом.

**Windows.** Clang (LLVM для Windows) и MSYS2 с окружением MINGW64 (`C:\msys64\mingw64`:
заголовки, runtime, `mingw32-make`; для тестов точности — пакеты `mpfr`, `gmp`). Visual Studio не нужна.
Другой путь к MSYS2 — переменная окружения `MYB_MINGW_ROOT`.

```
cmake --preset windows-dev
cmake --build --preset windows-dev --parallel
ctest --preset windows-dev
```

**Linux (Gentoo и др.).** `clang`, `ninja`, для тестов точности — `mpfr`.

```
cmake --preset linux-dev
cmake --build --preset linux-dev --parallel
ctest --preset linux-dev
```

Пресеты: `*-dev` (Debug, `-Werror`), `*-release` (`-O2`, проверки контрактов сохраняются),
`windows-ubsan` (UBSan в режиме trap), `linux-asan` (ASan + UBSan).

Тест `test_repro` сравнивает хеш результатов с эталоном: он обязан совпасть на любой
платформе, при любом уровне оптимизации и ISA (x86-64-v2/v3).

## Числовой контракт

IEEE-754 binary64, округление к ближайшему; библиотека не меняет окружение плавающей точки.
Сборка принудительно выключает слияние `a*b+c` в FMA и fast-math, а `-ffast-math` от
пользователя останавливает компиляцию. Подробно — `docs/PLAN.md`, §7.
